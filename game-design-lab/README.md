## 对后续设计的意义

把五种方向放在同一套问题下比较，为后续选择核心体验、安排美术资源和确定验证顺序提供依据。原作的成功不代表新项目的机会；本轮实验的反馈提醒我们，规则完整与流程可运行还需要通过实际吸引力验证。

## 运行与构建

直接双击 `offline.html`，或在本目录运行 `npm run dev`，打开终端中的本地地址。

- `npm run build`：保留历史实验，生成新的总结网页、离线包、总览图与 `docs/014-game-design-lab/` 静态副本。
- `npm run dev:game`：启动独立佣兵实验。
- `npm test`：运行保留的机制测试。

构建需要 Node.js、Python、Pillow 和 CJK 字体；Windows 默认使用微软雅黑。源数据为 `summary/content.json`，网页和总览图共享这一份内容。官方来源、分析边界与制作复盘可在网页末尾查看。
