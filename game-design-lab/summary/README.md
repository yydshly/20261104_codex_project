# 五款游戏，五种设计方向

本轮把主入口从游戏样片改为设计参考总结，整理原作特点、我们的理解、扩展提案和制作复盘。没有继续增加游戏功能。

- [当前网页](../index.html) / [单文件离线版](../offline.html)：五款原作画面、可切换的玩法与美术分析、循环节点、横向比较、扩展提案、复盘及官方来源。
- [完整总览 PNG](../assets/design-map.png)：2400 × 2000，一张图包含五款作品的方向、循环、参考意义、美术语言、扩展提案和验证问题。
- [自包含 SVG](../assets/design-map.svg)：文字可选择，内嵌官方截图，可用于缩放与后续编辑。
- [内容数据](content.json)：网页与总览图共享的数据来源。
- [排版脚本](render-poster.py)：使用 Pillow 与本机微软雅黑进行可重复的中文信息图排版；本轮没有用新生成的游戏概念图或 AI 图像来替代原作画面。

## 内容边界

原作玩法和截图以页面中链接的官方商店、官方网站与开发者日志为依据。美术作用、参考意义、组合方案与验证问题是我们的设计分析。扩展方向没有被实现，也没有被玩家测试或市场验证。

五个方向：杀戮尖塔的临场构筑、星露谷的生活积累、暗黑地牢的承压远征、异星工厂的系统优化、战场兄弟的队伍经营。

保留这轮的关键教训：规则齐全与流程可运行，不能替代独特卖点、清晰的反馈和持续投入理由。历史实验通过次级链接进入，当前不作为完成品质的宣传依据。

## 构建与归档

在父目录执行 `npm run build`。构建保留 `research.html` 与 `iron-company/`，更新主 `index.html`、`offline.html` 和静态副本，同时生成 PNG / SVG。需要 Node.js、Python、Pillow 和一个 CJK 字体。

`legacy-index.html` 是历史实验的源模板；不要再把新的总结入口作为历史页面模板进行打包。
