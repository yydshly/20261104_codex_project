# 黑水渡口 · 美术来源

本任务使用内置 **image_gen** 工具生成四张独立图集，并复制到项目目录。原图保留在生成目录，没有覆盖或删除。完整提示词、原图路径、透明背景要求和参考关系保存在 [prompts.json](prompts.json)。未使用 CLI / API 回退。

| 项目文件 | 内容 | 游戏里的用途 |
| --- | --- | --- |
| [warband.png](warband.png) | 4×2 格，四名佣兵和四种劫匪半身棋子，透明背景 | 主武器造型、角色与先攻头像 |
| [alternates.png](alternates.png) | 4×1 格，同一组佣兵换装后的造型，透明背景 | 钉头锤、长枪、弩和战锤的可见换装 |
| [terrain.png](terrain.png) | 3×2 格，草地、道路、岩地、灌木、河水、泥地 | 地块纹理；与地图中的实际移动、遮挡和高度属性相对应 |
| [props.png](props.png) | 3×2 格，岩石、树、商车、围栏、营地、路标，透明背景 | 战场环境与护送目标 |

图集在 Canvas 中切片使用，草地通过镜像铺接形成连续地表。木桥、地形高度侧面、棋子底环、状态标记、技能图标、路径、箭矢、刀光、格挡、飘字和音效由代码实现。换装图以第一张图集作为人物身份参考。

美术采用低饱和土色、历史装备与手绘棋子方向。角色、地图和故事由本项目重新制作，未提取原作角色或战场素材。研究库里单独引用的原作截图继续保留原来源说明。
