# 潮光 · 海港守灯人

一款可从开场玩到结局、支持检查点续玩的三章单人浏览器动作游戏。玩家通过观察预警、挥击、冲刺与关间装备选择，恢复三座海港信标。目标是完成有成长与收束的产品流程，玩家通过实际操作理解系统的作用。

## 产品范围与验收

| 环节 | 产品行为 | 验收方式 |
| --- | --- | --- |
| 初次进入 | 交代目标与操作，选择新航程或已保存的检查点 | 新用户从标题开始，界面与世界状态对应 |
| 暮港 | 近战机械蟹，学习预警、躲避、拾取与激活 | 三枚灯芯、点亮信标、获得升级选择 |
| 雾礁 | 远程炮台与近战敌人组合，移动掩体改变路线 | 四枚灯芯、躲避弹道、激活第二信标 |
| 风暴灯塔 | 首领突进与扩散弹幕，半血进入第二阶段 | 击败首领、拾取核心、激活最终信标 |
| 成长 | 关间三选一，攻击、生命或冲刺改变后续参数 | 选择只结算一次，下一关和续玩保持选择 |
| 失败 | 说明生命耗尽或潮汐到达，从本关检查点重试 | 重试清空本关敌人、拾取、弹幕，保留已得升级 |
| 保存 | 以关卡入口保存检查点，浏览器刷新后继续 | 恢复关卡与装备，重复继续不会重复奖励 |
| 设置 | 声音、画质、减少动态效果，暂停时仍可操作 | 暂停计时与战斗，关闭菜单恢复焦点 |
| 结局 | 三座信标归位，显示总分、命中、受伤与用时 | 完整通关回放和最终状态截图 |
| 输入 | 键鼠、触控，菜单键盘导航 | 多指按住与取消、窗口失焦、手机横竖屏 |

## 游戏规则

移动、挥击与冲刺构成基础操作。挥击向附近目标自动转向，只命中攻击扇区内的目标。敌人用蓄力标记、动作与声音提前表达威胁。冲刺提供短暂无敌，冷却中仍能正常移动与挥击。敌人只在冲撞或弹丸接触时造成伤害。关卡掉落的灯芯有稳定 ID，拾取与升级各结算一次。

每关的观察与决策逐步增加，第一关学习近战反击，第二关处理远近组合，第三关综合走位与时机。每关完成后恢复体力，并选择航程装备。升级选择影响后续战斗，不以纯分数替代成长。

## 证据原则

旧版文件保留在 `baseline/`。它用于检查这次从单场原型扩展产品流程的实际变化，同时提供同场景性能基线。反馈开关仅用于感知效果拆解。它们均未构成模型能力的随机对照实验。

验证报告记录真实运行结果、浏览器环境、视口与测试路径。节省多少开发时间、对普通玩家是否更容易理解、长期可玩性，均需要独立试验才能形成结论。
