# 潮光 v2：资源工具实际采用

目标：在既有完整三章产品上，用携带代码与资源管线的 Skill 产生可体验变化，并保留同一产品的前后版本、配方与证据。

采用范围、贡献边界、具体接口、验收与成本统一记录于 [SKILL-USAGE.md](SKILL-USAGE.md)，以免多份规范出现冲突。旧版完整产品目标保存在 [DESIGN-v1.md](DESIGN-v1.md)。

交付包括可玩的当前版本、before-upgrade 完整旧版、research.html 对照展示、gallery.html 资产展台、四项固定来源、三份生成配方、构建脚本、声音录像及 evidence/v2 原始记录。

不把新玩法代码自动归因于资源 Skill，也不把未进行的模型对照写成效率证据。新增海面带来的性能成本和上游授权未确认状态必须随效果展示。
