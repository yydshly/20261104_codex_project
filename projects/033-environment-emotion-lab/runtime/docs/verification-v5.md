# 池塘 v5 核验记录

日期：2026-11-12。预览地址为 `http://localhost:5217/`，本机 Node 服务仅绑定 `127.0.0.1`。

## 本轮更换的内容

- 首页加载真实 GLB 资产：3Dima 的绿头鸭，以及 Poly Haven 的树木、蕨类、灌木和苔石。模型/材质许可与修改说明保存在各自资产目录并展示在网页底部。
- 鸭子原资产是静态模型；尺寸、水线、头颈/喙的有限变形、转身、巡游、随波浮动与互动由本项目控制器提供。不是外部骨骼动画包。
- 地表采用 `mud_forest` 扫描材质；森林 HDR 只参与环境照明与材质反射，画面中的树林和天空是实时几何/着色器。未接入视频或平面背景图。
- 水面使用局部风波、多方向细波、反射扰动与历史尾流。长波采样与鸭子浮动保持同一时钟，仍属于实时近似，不是完整流体求解。
- 修复叶片打包过程中的 RGB 编码错误，保留官方源像素颜色与透明通道；增加随光线、叶面朝向和昼夜变化的薄叶透射。
- 修复统一减面删掉独立叶片的问题：两种新树冠分别保留源资产全部 44,168 / 29,781 片叶，简化每片的几何，不用删掉大部分叶片来降低面数。
- 降低观察机位，分别调整桌面与竖屏构图；相机可在池岸范围内转动、在进入场景后缩放。

## 交互与加载

实际浏览器核验：

- 场景显示 `ready=pond-3d`、`modelVersion=authored-v5`、`lighting=hdr-ready`。加载时显示占位遮罩；任一必需模型或 HDR 失败会进入错误提示，不将占位体标为成功。
- 打开声音并呼唤一次：进入 `respond/attention`，随后 `quacks=1`、`lastSoundPlayed=true`，鸭子游近后进入 `rest`。这是播放路径与事件核验，不等同于主观音质评测。
- 点击真实画面中的池水：`interaction=water`，行为转为 `approach`，位置持续接近落点。
- 风力滑块与阵风按钮生效；水、叶片和环境声音使用同一风力来源。
- 关闭持续动态后，已观察到时间 `80.14`、位置 `1.227,1.337` 在后续读数中保持不变。另修复暂停时风力归零导致植被跳回初始姿态的问题；恢复时风强平滑过渡。
- 完整树冠接入后再次核验暂停：时间 `161.35`、位置 `-0.718,0.587` 在后续读数中保持不变。关闭声音时呼唤仍有动作，`quacks=1` 但 `lastSoundPlayed=false`，静音不会被互动绕过。
- 夜晚切换改变环境光、水色、窗光与萤火；静音按钮恢复 `aria-pressed=false`。
- 390 × 844 竖屏无横向溢出（文档与视口宽均为 390），操作面板可用。该检查使用桌面浏览器视口模拟，不代表真实手机性能测试。核验后恢复默认视口。

## 自动检查

`npm run check` 与 `npm test` 通过。测试包括：实际鸭子 GLB 的加载和尺寸、一次呼唤一次叫声、300 秒泳域边界、移除旧码头避障、随水面采样、暂停、资源释放竞态，以及水体无效输入处理、尾流生命周期和长时间风力变化连续性。

Node 测试不代替 GPU 着色器编译与美术验收，最终画面另以浏览器截图记录。

## 边界

这是可实时操作的 WebGL 场景。鸭子仍受 1K 纹理和精简网格限制，小屋与地形仍有程序制作部分；不能宣称达到摄影级效果。未取得原参考视频的可直接逐帧比较版本，因此不作“已达到原片质量”的结论。所有检查均未访问或修改 ReflectFlow。
