# 自主人物、双视角与户外阅读验收 · 2026-11-15

本轮先实际复现问题，再修正并复测。验收使用独立、无用户资料的 Chrome 本地实例，访问本机项目；WebGL 使用 ANGLE / Intel UHD / D3D11，画面包含原始模型、贴图、光照与实时骨骼，不是示意图或代码桩。

## 已复现与修正

- **持杯脱离身体**：原来杯子连碟子一起飘向腿上。现在碟子留在桌面，人物依次伸手、握杯、抬到嘴边、喝茶和放回；同一动作时钟驱动骨骼和杯子，手指增加基础屈曲，肘部向身体下方收拢。
- **茶桌超出手臂范围**：桌子改到摇椅手边，按实际关节长度定位杯子、书和持物目标。
- **脚底悬空**：检查了原始蒙皮鞋底的 149 个采样点。此前鞋底约高出脚凳 3 厘米；调整脚踝目标并加宽脚凳后，稳定靠坐时两只鞋底约位于 0.472—0.474 米，脚凳顶面为 0.470 米。
- **拿书缺少身体动作**：增加桌面书籍、双手托书与放回，阅读时低头并配合视线，保留呼吸与不规则眨眼；摇椅与身体有小幅协调摆动，双脚仍保持支撑。
- **书页和镜头问题**：修正第一人称书页倒置；拿书不再强行改变第三人称观察角度。第一人称阅读、喝茶的视线改为渐进调整，拖动可以接手。阅读时收起挡住书页的底部面板，顶部仍可展开操作与切换视角。
- **户外朗读位置**：MiniMax 仍播放原有三页文件；声源随手中的书移动，放下后留在户外桌面。透视切换不改变人物与音频的位置。

## 操作与实际边界

先点“去茶桌歇歇”，坐稳后可点“拿起书”“拿杯喝茶”。**B** 拿起 / 放回书，**C** 喝茶，**N** 开始 / 停止当前页 MiniMax 朗读，**E** 翻页，**V** 切换视角。持书时操作面板会收起，可随时从顶部展开。

这是同一实时场景内的程序动作适配，尚非动作捕捉级表演。手指使用基础屈曲，没有完整抓握物理；衣物没有布料碰撞，复杂动作衔接仍有继续打磨空间。测试 Chrome 启动、截图和软件环境会影响采集帧率，本轮不据此宣称所有设备均流畅。


第一人称近景修正了眼位与模型后靠的偏差。喝茶时镜头平滑退让约 14 厘米，视线轻微下移并面向庭院，避免低头直视衣领内部。近景仅隐藏眼位附近的头颈表面，手臂、上身和双腿保留原始完整蒙皮；已撤掉造成袖口破面的前臂变形试验。第三人称仍显示完整身体，持物、脚部和声源共用真实位置。
