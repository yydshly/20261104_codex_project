# 033 · 栖境：环境、情绪与沉浸体验研究

研究数字环境怎样通过空间、光影、自然声音、持续变化、主体活动和操作回应，构造温暖、放松、愿意停留的体验。以池塘与阅读角为起点，逐步完成房间—庭院—池塘连通空间、第一与第三人称、连续阅读动作、持物与座椅接触、自然录音及 MiniMax 位置朗读。

**“环境构造情绪，引发沉浸体验”是本次的设计工作假设。已有成果是可操作的实时原型、实现方法与有范围的验收；稳定情绪效果、长期使用和产品价值仍需验证。**

## 研究方向与问题

研究对象是**环境与人的活动怎样形成一致体验**，可以用于游戏场景、自然陪伴、阅读、专注、日常整理或共同在场。先确定人在过怎样的一刻，再决定这个地方怎样呈现和回应。

1. 主场景怎样给人可信的所在，辅助的光影、材质、声音和微小动态怎样指向同一种感受？
2. 现成优秀模型、自然录音与同源动作能提供哪些基础，仍需哪些空间与时间编排？
3. 怎样让水、树、雨和动物持续自然变化，同时保持低打扰和清楚的操作回应？
4. 第一、第三人称怎样控制同一个主体，完成连续移动、坐起、取放书、翻页与喝茶？
5. 重心、视线、手脚、椅子和物件的接触怎样成立，镜头与声音怎样跟随活动？
6. 怎样区分技术功能成立、实际画面与听感自然、真实使用价值三个层次，并保留可复用的方法？

### 阅读动作与接触

动作链为**坐下 → 拿书 → 阅读翻页 → 放书 → 起身**。拿书前先看桌边并探身，书在握住前留在桌上，抬起后由另一只手接应。翻页时一手托书、一手扫页。起身请求在持书时先排队放书，落稳与松手后再收脚、前倾和起身。

原人物网格、蒙皮和材质保留。新增 9 个官方同源 FBX 输入，转换裁切成独立的 8 个动画片段，约 2.74 MB。原生坐姿呼吸为基础，肩背与颈部变化为附加层。坐下起身、书本交互和接触仍是本项目适配，不能称作已有完整原生“坐下读书”动捕。

用户指出的坐垫穿模经实际网格检查成立，最初 13 个采样点进入坐垫，最深约 3.44 cm。修复从真实椅子烘焙支撑表面，在骨骼动作之后检查蒙皮臀腿并校正骨盆，再重算手脚与持物关系；脚部在世界坐标中分阶段落地。保留完整人物网格，未靠隐藏臀腿掩盖问题。

## 我们形成的理解

**主场景 + 感官辅助 + 主体活动 + 共同状态 + 实际验收**，共同组成体验。

- 主场景确定活动、观看距离和身体所在。室内阅读与池塘观察可用同样方法，但注意力落点与核心模拟不同。
- 光、材质、声音和动态需要共同指向一种时刻；强度、尺度和出现时机一起判断。暖灯、纸面和窗外雨声要相互支持。
- 真实感来自许多一致的小关系：比例、接地、反光、接触、重心、目光与时间节奏。好模型和好动作是重要基础，仍需在具体场景中编排。
- 自然变化需要不同时间尺度。连续风、缓慢环境变化、局部细动和短暂操作反馈，可以减少固定周期与机械重复的暴露。
- 一份位置、天气、书页和动作状态安排视觉、声音与镜头。相同事件可触发不同时间尺度的反馈，避免各部分各自运行。
- 程序检查回答有限值、边界、生命周期与采样接触问题；实际画面和听感回答自然与连续；真实活动和持续使用反馈回答产品价值。

## 可以复用什么，哪些需要适配

- **已有底座**：有来源的资产、PBR/HDR 准备、天气与水滴逻辑、混音与静音、暂停/取消/释放及来源账本。
- **同类场景适配后复用**：水面、波纹与尾流；实例植被风动与同步阴影；人物基础动作和阅读阶段；双视角、真实眼位与镜头避障；位置声源与混音。
- **必须重新校准**：池形、岸线与尺度；新角色的比例和绑定；椅子支撑面、脚点、手握点、书和桌的位置、重心、镜头距离、灯光及声源布局。
- **尚待统一**：面向任意场景的配置框架、资产检索与自动接触求解、真实内容与产品数据层。

建议顺序为：定义生活时刻 → 选择优质素材 → 编排空间、光、声与动态 → 接上活动和回应 → 实际体验验收。完整手记提供可修改复制的场景卡，以及雨窗书桌、夜间整理角、双人阅读小屋等草案；计时、保存、真实书库和联机并未随草案实现。

## 检查范围与历史记录

此前实际浏览器检查覆盖起身出门、到池边返回、双视角、室内外持物与动作链。用户对早期往返听感的反馈为“整体连贯，没有明显突兀”。2026-11-16 接触修复后的记录包含 14 个浏览器阶段，页面与着色器错误为 0；这不是跨设备性能保证。

独立的实际网格核对覆盖呼吸、拿书、阅读、翻页、放书、起身、再次坐下共 134 个采样时刻，最大残余重叠约 **0.75 mm**，低于 2 mm 回归阈值；并另有靠背检查。采样验证不等同于完整衣料、软垫碰撞或所有动作与角度均无穿插。
