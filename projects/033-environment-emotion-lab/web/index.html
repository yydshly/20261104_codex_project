01 / 研究方向

怎样让一个场景，
成为可以进入的生活时刻？

我们的对象是环境与活动的组织方法：先定义人在过怎样的一刻，再安排这个地方怎样呈现、变化和回应。

空间与感官

主场景建立所在

用有来源的家具、植物、材质和真实相对尺度，组织室内外视线、冷暖、明暗与触感。

自然变化与声景

让环境持续生活

水面、树叶、雨滴与鸭子有不同节奏；自然录音、短反馈和朗读各自承担清楚的角色。

主体与真实活动

让人有事可做

把阅读、行走、靠坐和喝茶放到空间里。身体动作、目光和物件接触支持正在做的事。

共同状态与验收

让关系保持一致

人物位置、天气、书页和动作阶段共同驱动画面、镜头与声音；用实际运行发现不连贯之处。

03 / 形成的理解

一致的环境线索，
与可信的参与关系。

“环境构造情绪，引发沉浸体验”是指导制作的工作假设。用户偏好、当下情境与活动都会改变感受。

  1. 环境

    我在哪里

    主场景、空间关系与物件尺度建立可信的所在。

  2. 情绪方向

    这里是什么感觉

    光、材质、声音和节奏共同指向温暖、安静与松弛。

  3. 在场与自主

    这里与我有关

    自己行走、拿书、调灯，操作获得连贯且克制的回应。

  4. 沉浸

    自然进入一件事

    注意力进入阅读、观察或休息，随时可以退出。

主场景 + 辅助线索

房间、池塘和活动位置提供主体结构；光影、自然声、材质、风雨与微小动态扩展感官信息。每个元素都服务于同一个时刻，强度与出现时机一起安排。

优质模型 + 动作 + 接触

成品模型提供细节，同源动作提供身体运动基础。重心、脚点、握点、视线和镜头仍要适配具体椅子、书与空间；人物呆板不能只靠更换模型解决。

一个事件，多个对应反馈

拿书：看向桌边 → 探身伸手 → 书离桌 → 另一只手接应 → 进入阅读；相机与朗读声源跟随同一动作状态。

停雨：空中雨线淡出 → 玻璃残水缓慢消退 → 自然雨声降低；几层变化各有时间尺度。

04 / 价值与意义

让数字内容，
在生活里有一个位置。

当前积累、价值目标与下一步验证
层次当前可确认的部分希望形成的价值 / 如何继续验证
对使用者能自主进入环境、走动、坐下阅读或短暂休息，声音可选。更容易开始、舒服地停留、愿意回来；需用真实内容和连续使用反馈验证。
对产品阅读与自然观察已有可操作原型，环境能承载活动。可探索阅读、专注、日常整理、自然陪伴与共同在场；分别验证需求、内容、退出负担与使用频率。
对研发已有资产账本、场景模块、共享状态、双视角、动作阶段与声场。后续按用途复用，减少重复起步；需记录新场景的人工适配、失败点与实际耗时。
对判断与验收已有真实截图、视频、程序检查与有范围的网格测量。区分功能成立、美术自然、听感连续和长期价值；每类问题用对应证据回答。

尚未测量开发省时比例、长期情绪改善、留存、学习收益或商业收入，不将这些目标写作已实现成果。

05 / 可复用的方法

保留工作的底座，
重新定义一个生活时刻。

当前方法在两类环境中实践，尚未全部抽取成面向任意场景的统一框架。

已有底座

资产、状态与生命周期

有来源的模型、PBR 与 HDR；天气与水滴逻辑、混音、静音、后台暂停、取消与资源释放。

适配后复用

人物、镜头与声场

动作阶段、双视角、眼位与镜头遮挡、位置声源可沿用组织方式；角色比例、障碍、道具与声源布局要重标。

必须重新校准

场所与接触关系

新池形与岸线、新椅子的支撑表面、书的握点、脚部支撑、重心与光照预算，需要在实际运行中调整。

定义生活时刻 → 选择优质素材 → 编排空间、光、声与动态 → 接上活动和回应 → 实际体验验收

复制与修改场景卡 ↗人物动作与接触方法 ↗摘要、源码与发布方法 ↗

06 / 检查范围与下一步

先让活动成立，
再围绕真实使用打磨。

已有证据

分清不同检查回答的问题

既有浏览器完成往返、双视角与动作链记录；用户反馈往返声音“整体连贯，没有明显突兀”。座椅检查覆盖 134 个采样时刻，最大残余重叠约 0.75 mm，低于 2 mm 回归阈值。

当前边界

保持原型的真实范围

风雨、水与声音为实时近似；手指、衣料与软垫仍简化。大模型首次加载、跨设备性能、长时舒适度与稳定情绪效果继续验证。

产品化时

围绕一种用途做深

先选人群与活动，接入真实阅读或任务内容，再做进度、可靠保存与必要的记忆。联机、自由对话与在线生成需要独立设计和验证。

134 个时刻与约 0.75 mm 来自 2026-11-16 的实际网格采样，不等同于完整碰撞或所有动作、角度无穿插的保证。此次公开发布另做包内引用与依赖、引导图一致性、线上资源及真实页面检查。
