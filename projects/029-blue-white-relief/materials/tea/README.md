# 品牌上新模板 · 山白 / 松间

虚构茶品牌的春日上新展示样板。主视觉、茶器升汽与山水动态均复用青白造境项目已有素材，没有新增图片或视频生成消耗。

直接双击 `index.html` 即可查看完整访客页面。双击 `studio.html` 打开本地模板编辑器，可以换品牌、文案、配色、静帧、视频和访问链接。两份HTML的素材、样式与脚本全部内嵌，不需要网络或安装依赖；桌面和手机布局均有适配。

可观看茶器与山水影像、暂停或重播、打开大幅影像、切换三种茶席时刻，并下载茶器主视觉。影像播放一次后停留，不假设其无缝循环。系统开启减少动态效果时不自动播放。

品牌名、系列名与页面文案均为此次样板的创作概念；不是实际在售商品，没有虚构价格、产地、功效、客户或销售入口。

使用方法：在编辑器中载入“山白”或“松间”示例，修改内容，必要时从本机替换图片和视频，再点击“导出完整网页”。下载的HTML可以复制到其他目录或其他电脑后直接打开。点击“保存配置”会导出JSON，包含替换的本地素材；之后用“导入配置”恢复编辑。修改仅保存在当前页面会话中，请主动导出；没有服务器上传或浏览器后台草稿存储。

可选商品区默认隐藏。填入真实商品名称、图片和其他资料后再启用；没有填写名称与图片时会阻止导出。商品或咨询链接只在填入完整HTTP(S)地址后显示，不提供支付或订单服务。演示没有真实商品资料，不把茶器样图记作真实茶叶商品验证。

`brand.config.json` 是默认品牌、系列、配色、文案、素材及链接的集中配置；`presets/songjian.json` 是复用同一批媒体的另一份虚构概念。文案中的 `{{品牌}}`、`{{系列}}` 自动替换为配置值。本地素材支持PNG/JPEG/WebP/GIF图片和MP4/WebM视频；图片上限20MB、视频上限40MB。视频能否播放仍取决于浏览器支持的具体编码。

维护入口为 `page.html`、`styles.css`、`app.js`、`brand-render.js`、`template-core.js` 和编辑器的 `studio-page.html`、`studio.css`、`studio.js`。执行 `[本机路径已省略] -X utf8 build.py` 同时重新打包 `index.html` 和 `studio.html`；此过程不调用生成服务。素材只内嵌一次，访客页从原先约16MB降至约5.3MB。

`verify.mjs` 检查默认访客页面；`verify-studio.mjs` 检查实际编辑、素材替换、配置回读、独立网页导出、可选商品区和手机布局。它们使用本机已有的隔离无界面Chrome，报告与截图在`reports/`。`reports/template-export/`中的商品和品牌字段仅为验收数据，不是另一份真实商品案例。

`assets/` 中四份素材均从 `../blue-white-relief-lab/` 按原字节复制。两段视频采用第二轮曝光匹配与去音轨交付版；原生模型的曝光/无声问题不因此记为通过，原始验证与来源继续保存在原研究项目中。
