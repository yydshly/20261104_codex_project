# 成品人物：动作与带路初版

用户于2026-11-14明确：先用完成度较好的模型实现一版可用演示，面貌、眼镜、发型与深蓝卫衣可在以后按需要扩展。本版选用已在玻璃屋实际比较的 Microsoft/Rocketbox Male Adult 10（红色运动夹克）。默认入口现在是可动演示，静态对照用 `?study=1&hero=rocket10` 保留。

## 使用

- 「挥手」「示意」「看海」播放骨骼动作，结束后回到站立呼吸。「停下」中断带路并站立。
- 选择露台、屋内或近岸，人物沿露台、滑门通路与台阶行走，相机跟随；「开始导览」依次走过三个地点。
- 「人物视线」「跟随人物」「自由环视」「近看人物」可切换观看方式。
- 暂停按钮同时暂停人物动作、行走和海面；点击新的动作或地点会继续播放。
- 可下载当前GLB，保留80骨骼和5段动作。无换装，后续可扩展。
- 「自己走动」或WASD/方向键可直接控制人物，拖动调整观看方向；手机用方向按钮。选择地点恢复带路。玻璃、家具、露台边缘有本场景的简化碰撞。

## 来源与处理

模型、贴图与动作均来自 [Microsoft/Rocketbox](https://github.com/microsoft/Microsoft-Rocketbox)，MIT许可。许可全文为 `LICENSE.txt`；GLB内保留Microsoft版权声明。模型原始输入的记录位于 `../hero-candidates/rocketbox-downloads.json`，动作原始URL、大小及SHA-256在 `source/animation-sources.json`。

动作分别为 Idle（呼吸）、Walk（普通步行）、Wave（挥手）、Point（演示手势）、LookAround（转头）。其中Point是原作者presentation片段的前4秒，用于向景色示意，不宣称精确食指目标指向。动作源为121骨骼，按同库的80个命名关节世界变换烘焙到成品角色；保留原网格、蒙皮和服装，不使用此前被否定的占位人物。

水平根运动移除，场景路径或用户输入负责实际位移；步行动画按原片段实测位移/时长匹配路径速度。无跳跃片段按鞋底最低点作地面校正。2.9网页另加foot-placement.js的脚部IK、落脚锁定与抬脚过程，使用实际台阶高度及鞋底范围，修正此前路径高度近似造成的穿模。此适配在网页运行时执行，下载的GLB仍为5段原始基础动作，不包含场景台阶动作。

`../../character/build-rocket-guide.py` 是构建源，`../../character/rocket-guide.blend` 为工作文件。工作文件贴图依赖原始输入目录，不能只下载该blend就宣称已包含整个素材包。`manifest.json`保留动作来源帧、时长、采样检查、GLB哈希与行走速度。

本版以成品模型演示走动和视角引导，尚未声称达到原型相似度或最终角色美术品质。
