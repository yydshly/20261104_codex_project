# 地球里的小世界

一个可以从雪线徒步到海岸，再游进浅海的本地 3D 流域。地图有 15 个观察点，包含雪原小屋、峡谷、河岸木屋、蜂巢、蚁穴、牛羊牧场、热带森林、河口湿地、海岸沙丘、潮池、海湾、海带林和外侧礁石。沿途可自由走动，海面下有海草、礁石、海星、海葵和鱼群。

```powershell
npm.cmd ci
npm.cmd start
```

天气联动回归检查可运行 `npm.cmd run test:weather`，覆盖真实地形上的遮雨、沿坡径流、动物避雨和停雨恢复。

使用 Node.js 22 或更新版本。启动后用支持 WebGL 2 的浏览器打开 [3D 流域](http://127.0.0.1:4197/)。端口可用 `npm.cmd start -- 4198` 更换。

点「从雪线出发」进入第一人称。用 `WASD` 或方向键移动，按住 `Shift` 加速，拖动画面转身。往海里走会先涉水，再切换到游泳。游泳时按住 `C` 或 `Ctrl` 下潜，按住空格上浮，向岸边游可以回到陆地。手机上用左侧圆盘移动，拖动画面转身，入水后会显示「上浮」和「下潜」。按 `Esc` 或点「结束探索」回到总览。

页面下方的观察点提供快捷入口。「入水」「海带林」「外侧礁石」直接进入对应水域，在观察点附近点「水下导览」可从当前水下站开始。总览可拖动、缩放和平移。点「一键导览」会跟着小岚走完整段步道和水路，到站后开始讲解。「上一站」和「下一站」也会沿路线移动。拖动或滚轮可调整镜头，点「回到小岚」恢复自动跟随。导览中按 `WASD` 或点「接管小岚」会暂停自动导览并交出人物控制。点「继续导览」，小岚会沿你走过的路线返回接管点，再接着原路线前行。自由探索时点「跟随小岚」可在第一人称和跟随视角之间切换。

要启用 MiniMax 旁白，将 [配置模板](.env.example) 复制为项目目录中的 `.env`。已有独立密钥文件时，填入 `MINIMAX_ENV_FILE` 指向该文件的绝对路径。也可在 `.env` 或启动进程的环境中设置 `MINIMAX_API_KEY`。修改后重启服务并刷新页面。默认调用 `speech-2.8-hd`，用 `MINIMAX_MODEL`、`MINIMAX_VOICE_ID`、`MINIMAX_BASE_URL` 可以调整模型、音色和接入地址。导览面板会显示 MiniMax 的状态。缺少密钥或服务暂不可用时，导览继续显示字幕。 [MiniMax 同步语音合成文档](https://platform.minimax.cn/docs/api-reference/speech-t2a-http)

雪线观察点能看到融水由细槽进入积水池，再从低处流入主河道。点「开始下雨」可在任何观察点查看降雨。雨滴随风下落，遇到地形或水面时产生溅水或涟漪，木屋的两侧屋檐会滴水。水流和海浪按简化规则计算，地形和生物模型是示意性的。

下雨后可拖动「雨量」滑条调整雨势。雨水逐渐汇入河道，使河流加速、变浑，低洼岸边会形成浅积水。牛羊会走到牧场雨棚下避雨，停雨后逐渐恢复活动。径流、浑浊度和积水的消退需要一段时间。

持续大雨会让河水缓慢上涨，沿与河道连通的低岸淹没浅滩；高岸后方的洼地保持独立。中游最大涨幅约 1.25 米，源头融水池保持原水位，外海水位由潮汐独立控制，下游的雨洪涨幅逐渐减小。停雨后径流仍需消退，水位随后慢慢回落，雨量面板会显示中游涨幅。人物站着不动也会随水深切换涉水或游泳，漂浮时跟着水面升降，下潜时保留自主选择的高度；退水触底后恢复站立。一键导览和特写暂停期间也会更新水位。

雨天的地面、岩石和木材会逐渐变深、出现湿润反光；屋檐下保留较干的区域。岸坡有顺着地势流向河道的细水迹，草地、砂砾和压实泥土上的积水以不同速度消退。蜜蜂会连续飞回巢脾旁的遮蔽处，地表工蚁退回巢口，地下蚁群继续活动；雨停后错峰恢复。

退水后，被河水淹过的泥岸会保留深色湿泥、细泥沙和最高水位留下的水痕，随后逐渐变干。小岚走过湿泥、湿砂时会留下左右靴底印，浅水落脚会溅起小水花和波纹；脚印、水花及脚步声共用真实落脚事件。第一人称、跟随视角和导览都支持，站住、腾空或游泳时不留脚印。石面和木台不会投出下面泥地的印迹，旧印迹会随时间淡去，再次涨水会将其洗掉。印迹与水花使用固定容量循环复用。

可直接打开[雨后浅滩](http://127.0.0.1:4197/?weather=after-rain#walk)，从退水后的泥岸以跟随视角开始行走，观察靴印，再转向旁边的浅水看水花。

湿靴子也会把水带到原本干燥的沙岸，留下深色湿脚印。左右靴底分别记录带水量，每次实际落脚会消耗一部分，因此刚上岸的印迹更深，走远后逐渐变浅。脚印中心和边缘分别保留水分，风吹、遮蔽和地面潮湿程度共同影响蒸发；边缘先干，中心稍晚褪去湿色。水分干透后，凹印和鞋底纹路仍然存在，直到风吹来的干砂逐渐填平、雨水磨钝边缘，或持续潮水冲刷将其洗掉。短暂的浅水覆盖只会暂时隐藏痕迹，退水后可以留下受损残痕；彻底被洗平的旧脚印不会在退水或再次下雨时复现。

「探索设置 → 风力」可比较静风、微风、和风、强风下的干燥和风蚀，风声录音和雨点飘移也随选择变化。降雨会先重新润湿凹印，再逐渐冲淡纹路；树下和屋檐的遮蔽会减轻风雨影响。湿度、凹痕深度和纹路清晰度采用压缩时间单独计算，使用贴合地形的光照与法线起伏呈现细小凹痕，不改变人物的行走碰撞地形。仍使用固定 128 个脚印槽位，存档会保存剩余湿度和凹痕状态，重新打开后接着变化。

可直接打开[海岸脚印预览](http://127.0.0.1:4197/?shore=footprints&tide=ebb#walk)，按 W 走入海水，再按 S 回到岸上，对比上岸的湿脚印与入水前的浅砂印；该入口避开水下礁石并稍微俯看脚下。

靠近岸边、面向较深的水面，按 **F** 或点击「F 跃水」可向前跃入水中。起跳保留重力轨迹，前方太浅、被岩石或建筑挡住时不发动；入水产生随冲击强度变化的水冠、飞溅、扩散波纹和落水声，身体短暂下沉后浮起。普通跳跃落水也会产生冲击水花。腾空过程中可以小幅调整方向，鼠标继续控制镜头。

在水面或浅水中按 **F 戏水**，小岚会拍水或踢起浅水；下潜后同一按键用于拨水，产生向上浮的气泡。正常游泳的手臂入水处会出现小水花，身后留下短暂的尾波，声音跟随实际动作。戏水期间仍可移动和转向。水花、泡沫、波纹和气泡共用固定容量粒子池，暂停或传送不会误触发落水冲击。

可打开[跃水与戏水预览](http://127.0.0.1:4197/?water=play&tide=ebb#walk)，从海岸边按 F 开始体验，入水后再次按 F 戏水，C 下潜、空格上浮。

雨声按空地、树下、水面和屋檐变化。棚下减弱直雨和风声，保留屋顶敲击及滴水；停雨后一段时间仍能听到屋檐和树叶的滴水。雨声使用本地程序合成，与环境音量、静音和旁白压低共同控制。

首次点击场景或「开启环境声」后，会播放随位置变化的流水、风声、蜂鸣和水下环境声。走动时有脚步或涉水声，停下、跳起或进入特写观察时脚步会停止。环境声可以单独关闭并调整音量，MiniMax 旁白播放时环境声会自动降低。

平缓河流、急流、海浪和风声使用四段 CC0 现场录音，已下载保存在 `assets/audio/`。录音经过响度匹配和两秒循环接缝处理，以原速度、原音高循环；浏览器只加载解码一次，重新静音或恢复页面时继续复用。来源、作者、授权及处理参数见 [录音说明](assets/audio/SOURCES.md) 和 `assets/audio/manifest.json`，右上角的 ⓘ 也能查看。录音加载完成后，环境声按钮显示「实录声开」。

四个声层独立混音：平缓河段保留近处细水声，靠近急流、坡降较大或雨后径流增强时渐入急流；海浪随岸线距离、海湾遮蔽和天气改变；风声随海拔、雨势、树下或屋檐遮蔽改变。水声来自各自的空间位置，远处会更轻、更闷，进入水下则整体低通并减弱水面声。旁白、音量、静音和后台暂停统一控制这些录音。雨点、脚步、蜂鸣及水下气泡等交互声仍使用原有程序音效。

可从[平缓河岸试听](http://127.0.0.1:4197/?audio=field#walk)开始，再用下方观察点切到峡谷、海面或雪线比较；「开始下雨」可听风声和水流随雨势渐变。

河鱼和海鱼会从当前位置感知小岚的完整身体，靠近时加速转向、带动邻近同群鱼散开，离开后逐渐恢复巡游。湿地里的鸟会提前起飞避让，安静一段时间后再返回；人物碰撞会随鸟的身体与展翅范围移动。木屋燕子的航线也会避开屋顶。河口水位在潮汐河段逐渐接到海平面，波纹与颜色渐变交接，海浪在入口减弱；湿地水面及波纹只会出现在实际有水的地面上。

环绕、跟随、导览和特写镜头均检查地形与建筑障碍，并根据视窗宽度留出近裁剪面的空间。河岸木屋的屋檐、山墙和烟囱也参与碰撞；低矮木台和台阶提供实际脚底支撑。鸟起飞后逐渐收腿，返回时伸腿、减速落地并收翅。蝴蝶会连续飞离靠近的人，潮池蟹会加快横移，离开后在各自活动范围内恢复觅食。蟹的特写跟随它的实际位置，仍能拖动环视及缩放，并避开遮住主体的前景礁石。

涉水越深，小岚移动越慢、抬脚越高；泥泞会延长脚掌支撑与拔脚动作，并略微降低速度。跳跃落地后有短暂屈膝缓冲，按落地强度播放低频冲击声，浅水和湿泥产生更明显的水花或泥点，干砂、草地和雪地有少量尘土或雪粉。较深涉水只留下水面波纹，不会把河底水滴直接喷到空中。

完整场景回归可运行 `npm.cmd run test:world`，涵盖天气、人物、脚印、动物避让、河口衔接，以及全 15 段路线在晴天和涨水状态下的人物碰撞与镜头扫掠。

潮汐采用约 ±0.42 米、4 分钟一个周期的演示。涨潮会将海水推入河口，退潮时河水更快流向海湾，高低潮附近潮流减缓，河流自身的出海流量仍然存在。雨洪与潮流叠加，小岚的漂移、顺逆流游速、鱼群位置与迎流摆尾、漂叶和流纹共用水流计算；河口上游逐渐减弱潮汐影响。潮位变化会带动浅滩的涉水/游泳切换，退潮后的砂滩保留湿润记忆。右上角可以切换涨退潮方向，换向保持水位连续。可打开[河口潮汐预览](http://127.0.0.1:4197/?tide=flood#estuary)，从河口水面直接体验。完整回归也覆盖高潮、低潮和雨洪叠加时的全部路线。

MiniMax 旁白首次合成后保存在项目的 `.cache/minimax/`，服务重启后会复用。缓存按讲解文本、模型、音色、接口和合成设置区分，导览会显示「已缓存」。该目录已加入 Git 忽略规则。

此前的 27 幕二维插画可从页头的「2D 场景图鉴」打开。插画中的直达链接使用 `/atlas#场景编号`，例如 `/atlas#droplet`。

河道里的小礁石、浅水树干和支柱现在参与局部绕流：迎水面减速，两侧分流，背水区出现较缓的回水。潮流换向时，回水区也随流向移动。小岚、鱼群、漂叶、水下悬浮物共用这一近似流场，近处细小亮纹显示水面流向；这是局部简化模型，并非完整流体求解。

小岚的外套、裤腿和靴子分别记录湿润程度：浅涉水先湿靴子，深涉水浸湿裤腿，游泳浸湿全身。湿衣颜色变深、反光增强，出水后衣角和靴子会短暂滴水，随后逐渐干燥；屋檐遮蔽会减轻雨淋。滴水和水面漂纹采用固定容量缓冲。

「探索设置」可选择自动、高清、均衡或流畅画质，并继续上次探索。行走、游泳及导览途中每五秒自动保存一次，离开页面也会保存。普通入口再次打开时会恢复人物位置、朝向、天气、潮汐、积水、岸边湿润记忆和衣服湿度；恢复位置会检查碰撞，必要时寻找附近安全位置。显式指定的场景链接优先打开对应场景，仍可从设置中手动继续存档。存档与音量、静音、跟随视角及画质偏好保存在当前浏览器的本地存储中。

切到后台时暂停世界模拟与声音，返回后继续先前的潮汐和天气进度，已解锁的声音会尝试恢复。自动画质根据持续帧耗时调整渲染分辨率，手动选择的画质保持不变。旁白继续复用 MiniMax 磁盘缓存。
