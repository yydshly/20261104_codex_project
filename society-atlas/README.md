# 见全 · 跨领域科普全景

研究如何帮助大众发现认知盲区，理解陌生行业的结构，找到所需基础和逐层深入的道路。以「社会全景 → 行业 → 工作方向 → 技能与思维方式」为主线，连接无明确想法时的浏览与有问题时的搜索。图解、案例和练习用于帮助理解，学习效果仍待用户试验验证。

[在线探索](https://yydshly.github.io/20261104_codex_project/005-jianquan-cognition/) · [产品目标与研究共识](https://yydshly.github.io/20261104_codex_project/005-jianquan-cognition/#research) · [完整研究摘要](../projects/005-jianquan-cognition/README.md)

引导图沿用已生成的[见全研究长图](dist/assets/jianquan-overview.png)，在总库索引和网页「项目总览」中查看。多模型事实审核与覆盖互补目前是待试点方案。

面向大众的行业、技能与思维普及网站。首页以世界全景图为主入口，点一个社会板块，查看与它相关的行业，再进入行业的技能和思维方式。二十个行业门类都能通过地图找到，同一个行业可以从不同板块进入。可以按页面上的路径返回原行业和板块。地图下方提供「看行业」「学技能」「练思维」快捷入口和既有专题。交通物流、制造和软件提供分段定位的交互情境。

「研究与共识」汇总讨论形成的目标、认知路径、设计演变、当前行业与领域内容、引用资料、多模型审核方案和后续工作。可从首页、项目总览、页脚或搜索进入 `#research`。目录可跳到对应内容，行业与概念清单直接连接现有讲解。

二十个行业门类均有一条代表性学习路线，可以从世界全景图进入。每条包含工作流程、入门到深入的技能与思维方法、自检标准，以及一项可切换观察方式的练习。例如，从「生产与交换 → 交通与物流」可切换准时率的分母，从「知识与技术 → 通信、软件与信息服务」可对照页面和接口响应。练习使用虚构记录，URL 会保留当前选择和来时的板块。

每个行业下有三个代表性工作方向，共六十个。点开后可以看这个方向负责什么、先补哪些基础、怎样深入，并完成一项小任务再自检。方向可以通过统一搜索直达，也可以返回行业案例或继续练习相关通用技能。

每个工作方向连接两个跨行业基础概念。概念页提供虚构情境、即时反馈、三步图解与其他行业的应用入口。「我还不确定」也可作为选择，读图后再试。概念可以从首页快捷入口或统一搜索打开，切换到其他行业后可回到原判断。

「测试与质量」「质量与检验」「作答评价与反馈」有可从搜索、首页问题入口和行业页进入的学习路线。每条包括初次判断、查证图解、参考成果和换例判断，可保存自己的解释。`#study/records` 汇总同一浏览器中的记录，`#study/sources` 说明原始依据、教学归纳与覆盖范围。各路线将原文链接与它支持的具体说法放在一起。

统一首页、领域总览、知识讲解采用三类共享页面模板。AI 与信息组织是并列领域，使用一致的导航、位置提示和阅读路线：AI 展开 8 个观察区域与 24 篇专题；信息组织展开描述、分类、关联、索引、检索、来源与版本 6 个分支与 7 篇讲解。软件与计算、教育与传播两个相邻领域各有 4 个分支和 4 篇讲解；AI 另有上下文/记忆/训练、生成与证据、工具行动 3 篇机制讲解。0.6.0 将“大语言模型”向下展开为 6 个知识部分、每部分 3 种理解深度，并补充 5 篇机制与 3 篇基础讲解；0.7.0 沿用该结构展开“AI 智能体 Agent”。0.8.0 继续展开“RAG 检索增强生成”。0.9.0 展开“提示词与上下文工程”，新增 6 个部分 × 3 种深度、7 篇机制与关系讲解、3 篇基础讲解，以及任务说明、上下文预算和多轮状态 3 个交互图解；关系图与输入更新流程连接 LLM、Agent 和 RAG。四个领域均提供“方向与路径”“怎样运作”“怎样形成”视角。

0.10.0 加入「公司知识库助手」项目路线。可以从首页直接进入，用一个虚构的公司现行规定案例贯穿任务、版本、RAG、上下文和核验。

没有明确问题时，可以从世界地图、职业起点或生活现象进入；已经有想法时，可以通过统一搜索找到相关内容。科普正文直接给出解释、图解、例子和边界。检索图解可切换旧版、现行版与无关材料，观察回答依据的变化；找书图解可切换“知道书名”和“只知道主题”，比较两种寻找路径；AI 信息去向图解可切换上下文、产品记忆与训练，比较同一句话在三种机制中的去向和边界。页面提供继续深入、跨领域和返回入口，URL 保留必要的阅读位置与返回上下文。

既有 AI 的 5 节连续导览、可选理解记录，以及社会全景的 14 个主题继续保留。新版可以浏览社会主题；旧版社会地图、历史视角和笔记仍可通过 `dist/society.html` 使用。原有 AI 功能的历史说明见 [AI-EXPERIENCE.md](./AI-EXPERIENCE.md)。

## 本轮可以体验的扩展路线

- 没有具体问题：首页的三个现象入口 → 网页请求 / AI 回答 / 学习理解 → 相关领域。
- 带着问题：搜索“AI 会记住我吗”“大模型”“网页”“证据” → 图文讲解；可按四个领域和社会专题筛选。站内搜索使用本地标题与正文匹配，不是实时 AI 问答。
- 从 AI 向外：AI 记忆图解 → 软件与计算 → 网页系统 → Agent 工具行动；AI 生成 → 观察、解释与判断 → 来源与版本。
- 从学习向外：教育与传播 → 看懂与会用 → 反馈修正 → 软件测试 / 信息组织。
- 新旧文章均有继续阅读入口。返回会保留近期来源、搜索筛选和图解状态；很长的跨域链会缩短更早的 URL 上下文，浏览器自身的后退历史仍可使用。


## 完整跨域漫游：AI 为什么会答错

首页下方现象入口与 AI 方向地图下方的案例入口均进入 `#roam/ai-errors`，站内搜索也可找到“跨域漫游”。起点展示整条路线，可按顺序阅读或直接进入任一站：

1. `generation`：比较直接给时间和带来源说明的两种表达，理解流畅与事实依据的区别。
2. `sources`：切换旧版通知、现行通知和转述摘录，对照发布者、版本、星期与适用范围。
3. `evidence`：点击观察、解释和判断，区分可对照的记录、待核查的原因、有条件的结论。
4. `return`：把原回答与有依据的回答放回同一问题，并提供回看、继续探索和可选理解记录。

路线状态由 `material`、`evidence`、`answer` 三个 URL 参数保存。前后站、目录、刷新、浏览器后退和深入阅读返回均保留选择；站内切换不会累积嵌套返回链。文章与领域总览通过 `back` 返回原站。

星桥图书馆、通知、日期和模型回答全部为教学虚构，未调用真实模型。最后给出 16:00 的条件性解释，也明确未测得真实模型的错误原因。

可选理解记录只在主动点击保存时写入 `jianquan.roam.ai-errors.v1`，与 `ai-atlas.v1` 和 `society-atlas.v1` 分开。未保存的文字仅在当前页面会话中暂存，刷新前需要主动保存。阅读与切换不生成掌握记录。

## 大语言模型：向下展开具体方向（0.6.0）

从 AI 的方向地图进入“大语言模型”，或直接打开 `http://127.0.0.1:4173/index.html#map/llm`。统一搜索也可以找到整张地图、其中的知识部分以及具体文章。

| 知识部分 | 主要内容 |
| --- | --- |
| `representation` · 文字表示 | 分词、token、编号、嵌入向量与位置信息 |
| `context` · 关联上下文 | 注意力、多个头与层、因果遮罩和上下文窗口 |
| `generation` · 逐步生成 | 条件概率、候选分布、采样温度和停止条件 |

| `adaptation` · 适配与系统 | 监督微调、偏好优化、提示、检索和工具 |
| `evaluation` · 评估与边界 | 任务条件、指标、错误类型、泛化和证据 |

每个部分都可选择“先认识”“拆机制与基础”“看应用与边界”。例如 `#map/llm?node=generation&depth=mechanism` 直接打开生成部分的机制层。基础既可以在地图内展开一句解释，也可以进入概率、向量、优化的完整讲解，再回到原部分和深度。

地图使用 `node`、`depth` 保留选择，文章使用 `back` 保留进入位置。经过另一篇文章或相邻领域后，阅读导航仍能定位到原来的 LLM 部分；旧 `#topic/…` 链接继续通过 `data-return` 使用既有返回机制。从旧专题继续阅读也保留 LLM 部分与深度，页面提供返回“阅读起点”的地图入口，浏览器后退可回到上一篇。很长的跨域链仍受既有 URL 上下文长度限制，优先保留即时来处。

三个可操作图解均只在本地计算，不调用模型、不生成掌握记录：

- 分词图解：切换中英文示例，查看片段、示意编号与向量之间的关系。边界和编号是教学构造，不是真实分词器输出。
- 上下文图解：切换水果/公司情境，比较当前位置关联前文的示意权重。权重由编辑设定，不是模型测量或词义置信度。
- 生成图解：切换温度，对同一组候选重新归一化；固定接上一个片段以展示上下文增长。候选数值是玩具模型设定，概率不等于事实正确性。

页面明确聚焦常见的自回归 Transformer 语言模型，并分别说明还没有展开的专业公式、模型变体和工程方法。完整验证过程记录在 `design-qa.md`。

## AI 智能体：从模型走向任务系统（0.7.0）

从 AI 方向地图进入“Agent”，或直接打开 `http://127.0.0.1:4173/index.html#map/agent`。关系图提供大语言模型、Agent 系统、信息组织、工具与运行程序四个可点击入口，说明各自承担什么工作；它们不是四个依次执行的步骤。

| 知识部分 | 主要内容 |
| --- | --- |
| `goals` · 目标与任务 | 任务范围、约束、依赖与完成条件 |
| `loop` · 行动循环 | 下一步选择、工具反馈、更新与停止 |
| `tools` · 工具与接口 | 参数、结果、权限与外部副作用 |

| `knowledge` · 资料与检索 | 描述、索引、筛选、来源、版本与证据 |
| `evaluation` · 控制与评估 | 授权范围、资源预算、完成证据与人工接手 |

每部分均提供“先认识 / 拆机制与基础 / 看应用与边界”。需要时可以就地展开基础提示，或继续阅读控制流与反馈、接口与结构化数据、证据与来源三篇基础讲解。新增的 10 篇文章均有正文、图解、例子、适用范围与参考来源。

可以实际体验以下连接：

- Agent → 行动循环 → 大语言模型的逐步生成：区分模型的一次输出与外围系统的连续行动。
- Agent → 状态与记忆 → 大语言模型的上下文边界：区分系统保存、当次输入与训练参数。
- Agent → 资料与检索 → 信息组织的检索、来源与版本：理解候选材料怎样成为可以判断的依据。
- 信息组织 → Agent 的资料部分，或大语言模型的适配部分 → Agent：从相关领域重新进入任务系统。

`node`、`depth` 保存 Agent 地图位置。跨到 LLM 地图时，新地图承担当前位置，返回仍连接进入它的 Agent 页面；文章中的图解参数和近期返回路径保留在 URL。旧 AI 专题继续使用既有返回字段，不写入新的掌握记录。

三个交互图解均为本地预设示意，不调用模型或工具，不授予权限，不发送或修改外部数据：

- 行动循环：逐步查看目标、调用提议、工具观察和决定，可切换成功或失败结果。本例只允许一次外部调用，用额度耗尽说明停止条件；真实 Agent 可能重复循环、改变路径或采用其他组织方式。
- 工具与权限：比较已允许的公开查阅和需要具体批准的发布动作，区分提议、程序检查与实际完成。按钮中的批准只改变示意状态。
- 资料与检索：切换现行、过期和缺失材料，观察能支持的结论与后续选择怎样变化；检索材料进入上下文并不等于更新模型参数。

本图聚焦常见 LLM 驱动的 Agent，不将该结构视为所有智能体的统一定义，也不把长期记忆、多 Agent 或某种工具协议列为必备条件。每个部分继续标注尚未展开的专业实现与方法。

## RAG：从资料走向有依据的回答（0.8.0）

从 AI 方向地图进入“RAG 检索增强生成”，或直接打开 `http://127.0.0.1:4173/index.html#map/rag`。首页推荐、统一搜索以及 LLM、Agent、信息组织中的相关入口，也可以进入这张地图。

关系图提供 LLM、RAG、Agent、信息组织四个可点击入口：LLM 使用本次上下文生成文字，RAG 把外部材料连接到生成，Agent 可以决定何时查询与是否继续查找，信息组织提供描述、索引、来源和版本。它们是职责关系，不是四个执行步骤；RAG 不要求使用 Agent 或向量数据库，把检索材料放入输入也不等于重新训练模型。

| 知识部分 | 主要内容 |
| --- | --- |
| `ingestion` · 资料准备 | 解析、分块、元数据、索引、来源与版本 |
| `retrieval` · 寻找候选 | 问题与查询、关键词、语义与混合检索 |
| `ranking` · 筛选与重排 | 条件过滤、相关性排序、重排、冲突与覆盖 |
| `context` · 上下文组装 | 输入预算、选取与去重、出处、条件与材料边界 |
| `generation` · 依据生成 | 条件生成、主张与引用、依据不足与冲突 |
| `evaluation` · 核验与更新 | 查准与查全、回答依据、分层定位与更新检查 |

每部分均可选择“先认识 / 拆机制与基础 / 看应用与边界”，共 18 条分层阅读路径。新增 7 篇机制与关系讲解和 3 篇基础讲解，均含科普正文、四步图解、例子、范围说明、相关方向与参考来源。基础可在地图中先展开一句解释，再进入片段与上下文、相关性与相似度、查准查全与分层评估的完整页面。

双流程图把资料新增或更新时的准备，与问题到来后的检索、筛选、组装、生成和核验分开。节点可以点击进入对应知识部分；反馈可能回到前面的任何环节，不把六部分视为所有系统必经的固定顺序。

三个交互图解共用虚构星桥资料馆的借阅规则，状态保存在 URL 中：

- `#article/rag-ingestion?chunking=fixed`：切换 `chunking=fixed|semantic`，比较机械截断与按完整句切分，检查“珍本”与“仅限馆内阅览”的关系是否保留。按句切分只是示意，不保证适合所有资料。
- `#article/rag-ranking?method=keyword&filter=off&rerank=off`：切换 `method=keyword|semantic|hybrid`、`filter=off|current` 和 `rerank=off|on`，观察旧通知、现行珍本规则与展览纪念册说明怎样进入候选和上下文。三种检索顺序与重排判断由编辑预设，不是方法优劣实测；只取第一条是为了展示选取差异，不是通用建议。
- `#article/rag-generation?evidence=full`：切换 `evidence=full|partial|none`，比较完整依据、丢失对象的“可外借”片段与没有依据时，哪些主张受到支持。不完整片段下的错误回答被明确标为刻意错误示例，引用标记不能代替证据检查。

上述图解不访问 API、不计算真实嵌入或模型评分，也不调用语言模型；材料、排名和回答均是本地教学预设。阅读与切换不自动生成掌握记录。

地图用 `node`、`depth` 保留知识部分与深入层级，文章用 `back` 保留进入位置和图解选择。例如 `#map/rag?node=retrieval&depth=mechanism` 直接进入检索机制层。可从 RAG 跨到 LLM 的上下文、Agent 的资料与行动循环、信息组织的描述与来源，再返回原来的地图部分；进入另一张地图后，由新地图承担当前位置，返回仍连接进入它的页面。刷新和近期阅读返回保留参数，较长的返回链继续遵循既有长度限制。

本图聚焦常见文档问答型 RAG，并说明尚未展开的多模态、数据库、知识图谱、专业排序和工程实现。检索质量、回答是否忠实于材料、材料是否真实且适用分别讨论，避免把找到资料或附有引用当作可靠性的保证。

## 提示词与上下文工程：安排每一次模型输入（0.9.0）

从 AI 方向地图进入“提示词与上下文工程”，或直接打开 `http://127.0.0.1:4173/index.html#map/context`。统一搜索支持“提示词”“上下文工程”“prompt”和“context engineering”等入口，地图和具体讲解都保留所属方向。

关系图把任务表达与整次输入的准备放回 LLM、Agent 和 RAG 之间：LLM 处理当次输入并生成输出；RAG 找到外部候选材料；Agent 根据任务与反馈推进多轮行动；提示词与上下文工程贯穿目标说明、资料组装和状态更新。图中连线表示职责关联，不表示必须依次调用四个系统。单次问答也需要组织输入，术语边界并非唯一，通常调整输入不会因此更新模型参数。

| 知识部分 | 主要内容 |
| --- | --- |
| `task` · 任务与目标 | 目的与对象、输入输出、约束缺口、完成条件 |
| `instructions` · 指令与结构 | 任务要求、角色背景、层次分隔、冲突与信任边界 |
| `examples` · 示例与输出 | 示例模式、字段格式、代表性、结构与事实的区别 |
| `selection` · 材料与组装 | 窗口预算、相关性去重、条件来源、顺序与压缩 |
| `state` · 状态与记忆 | 会话历史、任务进展、外部保存、按需取回与更新 |
| `evaluation` · 验证与边界 | 成功标准、对照样例、错误定位、回归与适用范围 |

六个部分各有“先认识 / 拆机制与基础 / 看应用与边界”，共 18 组深入路径。新增 7 篇机制与关系讲解、3 篇基础讲解，均含正文、静态图解、构造示例、范围、参考来源和继续阅读。基础为输入输出与约束、token 与输入预算、对照与验证，可以先在地图中展开提示，再进入完整文章。

可点击的更新流程是“说明任务 → 准备输入 → 检查结果 → 更新状态”，下一轮可以返回需要修改的环节。六个知识部分是一种阅读框架，不是每次必做的六步操作。

三个互动沿用虚构星桥资料馆的规则：“普通资料可外借。珍本仅限馆内阅览。”

- `#article/context-task?brief=vague`：切换 `brief=vague|explicit`，比较笼统请求和明确目标、材料边界、输出要求的说明。右侧展示可以检查哪些条件，不生成模型答案，也不把提示更清楚等同于一定答对。
- `#article/context-selection?strategy=all&window=short`：切换 `strategy=all|focused|compressed` 与 `window=short|long`。总容量为教学设定的 10 / 14 格，输出预留 2 格；按原顺序放入可能被无关历史和重复摘录占满，选择本题所需可以保留两条规则，错误摘要则会丢掉珍本限制。格数不是实际 token、费用或注意力测量，按序装入也不是平台的自动截断策略。
- `#article/context-state?memory=none`：切换 `memory=none|note|stale`，比较追问“那珍本呢？”时没有带入记录、带入现行任务记录、带入旧规则 A 的条件差异。图解区分系统保存与本次可见，保留“未查是否预约”这个未知项，不把保存过的信息当作现行事实。

地图用 `node`、`depth` 保留知识部分与理解深度。例如 `#map/context?node=selection&depth=mechanism` 直达材料组装的机制层；文章用 `back` 保留近期来处和图解选择。跨到 LLM 的上下文、Agent 的状态、RAG 的材料组装后可以返回，进入另一张地图时由最近的明确地图决定阅读归属。刷新恢复 URL 中的选择；很长的跨域链仍按已有规则缩短较早的上下文。

所有互动仅在本地展示预设材料与计算，不访问真实模型、分词器或记忆服务，不执行工具、不保存跨会话记忆，也不把浏览和点击记为掌握。更长的提示、更大的窗口、合法的输出格式和保存过的记录，都需要分别检查实际任务效果、证据与适用范围。每个部分注明尚未展开的专业实现；当前只提供本地版，未执行部署。
