# 从纸面版画到可复用交互能力

研究日期：2026-11-15。对象：[Ann Nguyen / @ann_nnng 原帖](https://x.com/ann_nnng/status/2120156122133004665)。目标是先看效果，再理解机制，最后判断怎样服务我们现有的创作和产品。

当前修订：用户明确要求参考**风格与氛围**，自主实现效果。本地第二版使用原创的溪桥、田间与花园；参考区继续保留原作，渲染器不读取或采样原作媒体。返修原因、实现配方和图像验收见 `revision-v2.md`。

2026-11-22 补查作者后续回复，发现并核对了 [Paper River 正式体验页](https://www.bubbbly.com/paper-river)。作者从原帖录屏引导读者进入四个可点的纸面小景。公开页面说明与采莲操作提示对应此前的录屏观察。它提供了体验入口，具体制作流程与开源许可仍待核实。完整研究与评论分析见 [研究总览](../research-summary.html#comments)。

## 先澄清研究对象

本轮确认的是一件公开的交互作品录屏，未确认一个可获取的开源代码库。作者写明“fishing and farming in an embossed paper drawing by Claude Fable 5.2”。作者的模型标注是作品来源信息，不能用来推导具体提示词、模型参数、源码框架、授权或稳定成功率。

原帖正文未附仓库或体验链接。11 月 15 日首次检索未定位到独立体验站，11 月 22 日沿作者后续回复补得体验地址。X 直读受到访问限制时，帖文和媒体地址通过公开 FxTwitter 元数据接口读取，实际封面与视频另行视检。目前尚无该作品的可确认开源仓库。

## 一、作品的效果是什么

### 1. 实际可见的层次

原片约 29.45 秒，公开最高视频尺寸标注为 1936 × 1516。本地保留来源提供的 918 × 720 MP4 版本，不把分辨率较低的研究副本称为最高原件。

- **纸的表面**：米白/灰白底，颗粒与纤维明显；主体的墨色也带表面起伏与不均匀感。
- **版画图形**：形体概括、少量黑色线面，辅以红、赭、橄榄绿或蓝灰。材质复杂，形体保持清楚。
- **尺度关系**：少量人物、船、树或田块留在大面积纸面中；画面呼吸感来自留白，而非满屏装饰。
- **动作关系**：主体主要保留在原位，局部内容发生小变化。底部可见四个场景缩略入口与暂停入口。

### 2. 四场景观察索引

| 原片位置 | 场景 | 直接观察到的内容 | 可提炼的交互问题 |
| --- | --- | --- | --- |
| 0–约 5 秒 | Water lilies / 采莲 | 莲花、叶片、人物与船；前后画面中花的位置/数量变化；画面提示可点花或叶 | 被操作对象的状态如何同步影响另一个对象？ |
| 约 6–14 秒 | The rice field / 稻田 | 红衣人物、长柄农具、树与田；操作前后农具位置和秧苗排列变化 | 一个局部动作如何在环境里留下结果？ |
| 约 15–20 秒 | The lift net / 抬网 | 人物、支杆、网与落日；网的弧度和高度变化；可见抬网相关提示 | 连续手势如何映射成几何形变？ |
| 约 21–29 秒 | First light / 晨捕鱼 | 两艘小船、人物、红日、水纹；局部鱼/水纹响应 | 多个独立对象如何同时保留状态？ |

时间区间来自抽帧的近似定位，不是精确切镜标记。本轮联系表为 0、3、6、9、12、15、18、21、24、27 秒；另取 1、8、16、24 秒作场景缩略图。没有对音频作判断，也没有操作作者原始应用。

### 3. 观感如何转为可操作实验

本地另写三组原创场景，验证两个问题：

1. 相同几何与配色不变时，材质参数能否明显改变表面观感？
2. 同一套状态反馈，能否从莲花采集迁移到种植和复盘状态？

“溪桥拾秋”让水面的秋叶沿弧线收进篮子；“田间晚风”让空田里的新苗从根部舒展；“雨后花园”让照料过的幼苗开出花枝。三个场景均有六个独立操作对象，支持任意顺序命中、按钮操作、饱和上限与当前场景重置。将状态迁移到复盘应用仍是未来方向。

## 二、原理：材质与交互是两套相接的系统

### 1. 可行的渲染方案，不等于作者实际技术栈

| 路线 | 适合什么 | 主要成本与边界 |
| --- | --- | --- |
| SVG 图形 + 表面滤镜 | 形状可控、对象较少、需要清晰命中的版画 | 复杂滤镜在高分辨率和移动设备上需测量；不自动获得真实三维 |
| Canvas 2D + 墨色/高度缓冲 | 多个绘制对象、像素级分析、无需框架的研究工具 | 像素着色在 CPU 上执行，分辨率提高后需节流或移到 Worker/GPU |
| WebGL 平面 + 高度/法线纹理 | 动态光照、更细表面、较大画幅 | 着色器、纹理、命中与上下文恢复都要管理；高度贴图不自动改变外轮廓 |
| 真实三维网格 | 纸厚、侧视、穿插、真实阴影与运镜 | 建模与资源成本更高，这个录屏本身不足以证明必须使用三维 |

本项目选 Canvas 2D，目的是看得见中间结果、完全本地运行和易于拆模块。未引入 Three.js，也未调用 SVG 光照滤镜；W3C 的表面光照模型用作原理依据。

### 2. 本地实际渲染路径

```text
原创场景几何 → 有限彩墨 + 独立的浅压印高度
固定种子 → 54,000 条短纤维 + 细粒噪声 + 微小起伏
                      ↓
纤维表面与浅压印的梯度 → 法线 → 漫反射
                      ↓
纸面起伏 → 彩墨缺损 + 轮廓微扰 + 不规则纸边
                      ↓
缓存静态版画 → 局部差分过渡 → 水纹 / 小蝶 → 展示画布
```

颜色和高度必须独立。例如，黑色人物可以比白色纸面更高；如果简单把彩色图转成灰度，深色就容易错误变成凹坑。参数面板允许单独查看这两张图。

当前以相邻像素差估计梯度；`normal = normalize(-∇(paper×grain + shallow_press×depth), 1)` 是关系简写。实际代码分别设置纤维与浅压印的强度，再归一化法线，参与方向性漫反射。纸纹固定在纸面坐标上，主体运动时整张纸不会闪烁。

这些关系可参考 [W3C Filter Effects 的漫反射表面定义](https://www.w3.org/TR/filter-effects-1/#feDiffuseLightingElement)。本项目是自己的简化实现：使用方向性漫反射和环境项，没有实现完整材质物理、真实投影或镜面反射。纸纤维由固定种子生成的短线、细粒噪声与底层起伏组成，参与法线，并驱动部分墨色覆盖变化；几何内部另画留白刻痕。没有将纸纤维重建为真实三维几何。

### 3. 本地实际交互路径

```text
点击画布 / 点击等效按钮
    ↓ 画面坐标归一化到 1000 × 630
物件命中，检查该物件是否已完成
    ↓ 只允许尚未完成的项改变一次
当前场景 completed:Set 加入物件编号
    ├─ 计数取集合大小
    ├─ 场景几何从集合重新派生
    ├─ 可读文字解释刚才的变化
    └─ 从前后帧提取局部差分，驱动拾取或舒展过渡
```

三个场景各自保留一份集合，切换题材不会混淆进度。六项完成后按钮禁用，不会重复累计。拾叶过渡约 1.15 秒，生长过渡约 0.95 秒；暂停时直接显示完成状态。刷新丢弃示例状态，页面不依赖 localStorage。

微动通过 [requestAnimationFrame](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame) 提供时间更新；绘制节流至约 15 次/秒，实际帧率取决于设备。静态材质只在场景或参数变化时重新计算，背景页面或画布离开可见区时停止微动绘制。系统要求减少动态效果时默认暂停，按钮仍可操作。

### 4. 三个原理实验

| 操作 | 应观察什么 | 它能证明什么 |
| --- | --- | --- |
| 固定颜色，将浅压印从 35 调到 0，再调回 | 图形边缘起伏减弱，纸纤维仍保留 | 纸面起伏与图形压印分别控制 |
| 光线从 315° 改为约 135° | 同一凸边的亮暗侧交换，主体身份不变 | 局部法线参与着色；并非仅全图调亮 |
| 拾叶后切场景，再切回来 | 秋叶、篮子与计数仍对应原来的物件状态 | 展示和文字来自同一份状态 |

这些实验检验本地实现，不检验原作者源码。保留原片与本地实验并列，避免将一种可行方案误称为源码考证。

## 三、它的价值与对我们的价值

### 1. 对创作：把风格关系从单张作品里抽出来

可复用资产不是“再画一次相似的船”。更重要的是将形体、纸面、墨色、局部动作和留白之间的关系写清楚。之后换成茶器、植物、书页、地图或建筑，仍然可以保持识别一致。

对我们：青白造境已有瓷质形体与局部微动研究；本项目补充纸面材质与状态互动。两者未来可以抽出共同的 `scene → surface → motion → interaction` 接口。**当前还没有跨项目抽取或改造共享引擎**。

### 2. 对产品：把操作和积累解释得具体

点击后场景里有一个确定变化，用户既能看到结果，也能知道原因。阅读章节、复盘条目、学习里程碑可以选择这样的表达。它有机会增加参与感和被珍惜的感觉，但不能从一条录屏推导出更高留存、更好疗愈或更高付费意愿。

对我们：交互效果实验室可以新增一个“明确输入 → 状态更新 → 局部反馈 → 累计结果”的案例；Cozy Emotion Lab 可以比较“只看图”与“可轻度参与”的差别。具体结果应由使用者完成任务和描述感受来判断。

### 3. 对工程：让生成能力成为能维护的生产方式

原作者标注模型，说明 AI 是其创作过程的一部分；没有公开完整过程，无法评估耗时、成本或迭代次数。对我们的启发是建立简报、实现、实际操作、核验与资产记录的循环。图形语法、材质渲染、状态逻辑和内容数据拆开后，后续 AI 修改更有边界，也更容易人工复核。

### 4. 与我们已有子项目的映射

| 我们的项目 | 可带走的能力 | 一个具体的下一步 | 当前范围 |
| --- | --- | --- | --- |
| `blue-white-relief-lab` / 青白造境 | 几何与材质分离、控制局部运动 | 用一份花朵几何比较瓷质/纸面，定义表面参数接口 | 已分析，未改动原项目 |
| `interaction-effects-lab` | 命中、状态、反馈、恢复的案例结构 | 把纸面进度反馈做成“原机制/产品应用”对照 | 已分析，未接入原项目 |
| `cozy-emotion-lab` | 温和的参与节奏与随时停止机制 | 相同内容下比较静态观看和轻交互体验 | 已分析，尚未做受众验证 |
| 日常复盘工具 日常库 | 已完成记录的只读、低打扰复盘表达 | 先约定脱敏统计格式，用人工选择的示例验证语义 | 只有示例花园，无真实库接入 |

日常复盘工具 属于重要日常库。未来如要接入，应由明确授权的数据导出/统计层产生一份只读输入，渲染层只消费它。必须保留时间口径、缺失和更正语义；不把可视化状态当作正式日记，不让展示层承担保存未完成编辑。这次未读取或操作其任何保护路径。

## 四、可扩展的理解

### 材质也是界面语言

“纸”可能暗示手作、出版、纪念与可保存的记录；“玻璃”可能强调层叠；“瓷”可能强调器物与克制。这些是表达假设，需要在具体文化和人群中验证。不是所有工具都适合装饰：精密检索、高频编辑与密集表格通常要先保证识别速度、对比度和空间利用。

**检验**：同一内容做中性平面和纸面两版，比较感受描述、查找用时与误点。不要只问“好不好看”。

### 动画可以解释状态

装饰动画告诉人“画面活着”；因果动画告诉人“你的动作发生了什么”。两者可以共存，但交互结果应该在停用动画后仍然清楚。连续动作例如抬网，可以进一步研究拖动位置如何映射网面几何和捕获状态。

**检验**：让使用者描述刚才发生的变化、指出结果位置；关闭运动后再次完成任务。当前本地没有实现原作抬网的连续网面变形。

### 数据可以成为景观

数据的目标不总是精确比较。个人回顾、文化叙事和纪念可以用植物、路径或物件累积来表达，但每个视觉元素都要有可解释的映射和文字数值。不能把缺失数据画成零，也不能把补录画成当天完成。

**检验**：用包含未完成、补录、跨日与更正的人工样例，检查画面和文字一一对应。目前是六个可操作的独立示例项，不具备上述真实数据规则。

### 作品可以成为主题模板或产品

节气贺卡、地方文化互动、阅读纪念页与品牌微展项，都可共用一套小型场景引擎。规模化的关键成本会转向原创内容、素材授权、移动设备适配和无障碍支持，而非不断换模型名称。

**检验**：先选一个受众、一个场景，交付一份从操作到导出的完整模板，再观察是否有人愿意重复使用。商业回报尚未验证。

## 五、后续路线与验收

| 优先级 | 建议工作 | 完成标准 |
| --- | --- | --- |
| P0 / 本轮 | 原作引用、三场景本地演示、材质层观察、价值分析 | 原片可播；操作和计数一致；可切层、暂停、重置与导出；证据边界清楚 |
| P1 | 抽出 `scene/material/state` 小接口 | 换一组明显不同的主体，不修改材质主循环；按钮和画布输入仍同源 |
| P1 | 移动端性能与可访问性实测 | 在一台明确型号的低端设备上测量输入延迟与耗电；键盘和屏幕阅读器可完成全部动作 |
| P2 | 抬网式连续几何互动 | 拖动与网面形变连续对应；释放后有可预测的状态，不靠预录视频切换 |
| P2 | 原创主题模板 | 一个完整新主题，包含素材授权、文本和导出；避免只换颜色当作迁移完成 |
| P3 / 单独授权 | 真实数据的只读复盘景观 | 约定数据格式与缺失/补录语义；校验跨日、重启、纠错；独立于正式库写入 |
