# 《悯农》第一轮试看

本轮目标：了解观众能否理解故事、能否自然看完、是否愿意再看另一篇。当前版本约25秒，第二幕为接水碗精修样片。先冻结这一版收反馈。

## 可交付给试看者

- [打开在线试看页](../deliverables/minnong-review/index.html)。使用缓存的旁白、四幕 GIF 和画稿，支持手动保存反馈。
- 右下角“留下试看感受”提供四道简短问题，保存为JSON文件后，由对方自行发回。页面不上传反馈，不要求姓名或联系方式。

本轮已在桌面Chrome以file协议、断网状态验证完整播放和导出；390像素布局也已检查。手机系统对本地HTML的打开方式不同，本轮不把布局模拟当作真实手机验证。Safari、真实手机和公共分享链接需后续单独验证。

## 先找五位，逐人观察

尽量包含不同使用背景，例如两位家长、一位教师、一位内容创作者和一位一般读者；找不到某类时，记录实际构成，不凑身份。用P01至P05编号即可。第一轮约5到8分钟一位，不收集姓名。

邀请文字可以自行复制发送（本项目未代发）：

> 我做了一个25秒左右的小故事，想知道别人实际看起来是什么感受。请解压后用电脑浏览器打开，按你平常的方式观看。中途不想继续也可以结束，再点右下角留下感受、保存反馈文件发给我。没有标准答案。

主持时先不解释故事寓意、动作设计或技术来源，不先说“第二幕更精致”。请对方按平常方式开始；卡住时先记下位置，必要时再帮助。记录是否需要帮助，并区分打开/浏览器问题和内容问题。

看完后保留原话，不争辩、不替对方改答案。可追加一句“你说的这个地方，能指给我看吗？”让对方指出具体幕或时刻。若要观察暂停或回看，等第一遍自由观看结束后再请对方尝试，并记下是否找到入口。

同一台电脑换下一位时，先确认反馈JSON已下载，再点反馈页上的“已确认保存，开始下一位试看”，避免带入上一位的回答和播放记录。

## 三个核心判断

1. **理解**：先看自由复述。人工评分2分为能说出劳作与一餐饭的关系，且提到父子间至少一个行动关系；1分为只记得诗句或零散画面；0分为误解或说不出。写下评分理由，不以关键词自动判分。
2. **出戏点**：保留具体幕、时刻和原话。两位以上独立提到同一问题时，优先修这一项。明显的功能故障单独处理，避免和审美反馈平均在一起。
3. **继续观看意愿**：“愿意”“看题材”“暂时不愿意”分开记录。不要把“看题材”算成无条件愿意。

收齐五份后，可暂以“四位能达到理解2分、三位明确愿意再看、没有重复出现的严重功能阻碍”作为是否进入下一轮的工作门槛。这是小样本的项目决策规则，不是统计证明，也不等同于已经适合正式发布。

播放覆盖来自实际音频时间推进，跳到结尾不计作接近完整播放。静读、静音、重听和未启动播放者要结合回答单独理解；技术记录不能证明注意力、实际听感或故事理解。

## 收回反馈后

将真实的story-review-*.json放到项目的feedback/inbox，再运行：

```text
npm run review:summarize
```

结果在feedback/summary：包含原文CSV、理解评分与归类的空白人工列，以及计数汇总。相同reviewId多次导出只保留最新一份；混合版本会提示，不合并作通过判断。原始JSON保留。

[主持人空白记录表](../feedback/主持人记录表.csv)供补记观察。自动化测试样例保存在reports/minnong-review，不能放进真实反馈收件目录。
