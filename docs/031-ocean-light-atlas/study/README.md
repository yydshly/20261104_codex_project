## 每项包含

- 一张处理未核实的原帖视觉参考条带、具体画面目标与适用输出。
- 三条可观察验收标准、两个容易跑偏的点、三步制作路径。
- 首轮实际出图的视觉差距与下一步，不以程序运行代替效果达标。
- 独立的制作参数、形态处理、配色、AI 提示词与实拍方法。
- 目标参考与当前程序化制作并排对照；原比例参考可放大查看。
- 人工验收勾选；修改参数时清除当前验收勾选，避免沿用旧判断。

网页当前制作按散景、星芒、流纹、泡沫、横向反射、浪唇和低对比水面等形态处理，逐项再调整构图与密度。导出成功仅表示文件生成；并不表示全部图像已经达到摄影参考的视觉效果，默认未自动标为达标。

## 二十项逐项扩展

新增「扩展方案」：每个基础效果分别展开深入细节、变化过程、组合效果、材质迁移四条路线，共 **80 份独立方案**。

每份都有具体目标画面、构图与机位、三步制作路径、三条验收标准、避免项和计划交付。40 份动态或组合方案另有连续的 0–2 / 2–5 / 5–8 秒镜头计划；材质迁移明确新的主体与材质。

- 从 20 项目录选择起点，或在扩展区选择基础效果；四条路线可独立切换。
- 「20 × 4 目标总览」可浏览全部 80 个目标并跳到完整方案。
- 可复制完整方案与生成指令，下载单项或全部方案；搜索也包含扩展目标。
- 当前扩展方向会在刷新后恢复，链接可用 `?effect=translucent-lip&direction=combine#expansions` 定位。
- 所有扩展均标为 **方案 · 待制作**；当前基础程序化稿不冒称为扩展成图或视频。

完整方案交付件：`deliverables/ocean-extension-plans-80.json`。基础效果 JSON 与条带素材包中的 20 份配方也各附四份扩展方案。

## 维护入口

- `index.html` / `studio.css`：二十项目录、对照制作、验收和配方。
- `effects.js`：20 项逐张资料与验收标准；继续创作以此为源。
- `extension-plans.js`：80 份目标、制作路径、镜头计划、验收与生成指令。
- `extension-view.js` / `extensions.css`：扩展方向、总览、复制和方案导出。
- `studio.js`：筛选、制作、验收、本地状态、复制与导出。
- `water-renderer.js`：多形态 WebGL 制作与二维兼容预览。
- `zip.js`：无依赖 ZIP 打包。
- `server.mjs`：本机预览。
- 初版 `app.js` / `studies.js` / `styles.css` 保留作历史参考，当前入口不再引用。

语法检查：`npm run check`；方案完整性与导出测试：`npm test`；更新静态 JSON 交付件：`npm run export:plans`。验证记录见 `VERIFICATION.md`。
