# v1.12 白屏复现、恢复与负载验收

日期：2026-11-15。全程使用内置浏览器，没有桌面控制。正常体验页自然视口846×919；独立验收页上方有62px工具栏，iframe采用剩余自然空间，没有覆盖设备像素比或视口。

已确认的故障：旧版发生真实WebGL Context Lost事件后，场景持续空白而UI与行走循环仍运行，未显示恢复提示或执行应用层恢复。通过verification/render-recovery.html按钮调用当前画布的WEBGL_lose_context扩展复现，截图context-lost-before-v13.jpg。原先那一次显卡/浏览器为何丢失上下文，未取得驱动层证据，不能断言由单一材质或内存分配造成。

修复措施：

- 新增图形恢复状态管理，丢失时暂停行走和绘制、清空按住的方向键，保留当前位置及路线。恢复事件后重新生成HDR环境光、后期缓冲、玻璃反射和阴影；绘制出首帧后才撤掉恢复提示。隐藏页签等待绘制时不因超时而误重载。
- 8秒没有恢复事件时，使用本页面独立sessionStorage键保存人物、视角、门状态、昼夜模式和未完成路线，自动重新连接一次。60秒内不自动循环重载，仍失败时提供手动恢复按钮；晚到的原生恢复事件仍可恢复原画面。
