Lyren 公开了四条对数旋臂、分层粒子和镜头路线的制作提示词，指定用 NumPy 计算、Pillow 绘帧、FFmpeg 输出视频。原帖展示成片与提示词，未附可审查的渲染源码。

我们的验证

两套渲染都用 θ = ln(r/r₀) / tan(p) + φ 摆出四条旋臂。成片固定种子，分别计算 12° 和 28° 的尘带与星点，再用同一镜头逐帧投影。工作台对照图用同一套轻量采样，也会锁住两边的图层和选帧时间。两种输出均为程序化示意。
