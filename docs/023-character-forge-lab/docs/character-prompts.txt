01 · 角色规格与制作简报
工具/用途：交给制作助手 / 角色美术
交付物：一份角色规格、分件清单、镜头与验收方案
验收重点：先明确目标；预算是本项目参数，不冒充 Riot 官方规格。

为原创英雄“赤霄”建立可执行的游戏人物制作简报。
身份：成年重装近战战士；武器：双手重戟；配色：暗铁、旧金、深红。
主要展示方式：MOBA 俯视战斗，兼顾英雄近景。
目标：达到成熟风格化游戏人物的结构可信度、轮廓辨识度和动作重量感。参考重装战士的设计原则，保留原创脸型、盔甲纹样和武器识别点。

请交付：
1. 角色性格、力量来源、身高/体型与站姿；说明游戏镜头下最重要的三个特征。
2. 身体、头发、头盔、胸甲、肩甲、护臂、裙甲、战靴、披风、武器的分件表与连接方式。
3. 正/侧/背视图要求、材质分区、可动关节范围、武器握持点与挂点。
4. 按目标设备拟定三角面、贴图、材质批次、骨骼、LOD和显存预算，并说明取舍；不要把预算写成质量证明。
5. 分别列出静态美术、变形、动作、引擎和性能的验收项。
先完成站姿、跑步和一次重击的最小样板，通过后再扩技能。标注未知信息，不虚构生成工具已执行。

02 · 人物概念图与统一视图
工具/用途：图像生成工具 / 概念设计
交付物：角色设计图，作为后续三维参考
验收重点：检查正侧背的装备一致性；漂亮的图不能证明三维资产已完成。

设计原创风格化 MOBA 重甲战士“赤霄”，持双手重戟，配色为暗铁、旧金、深红。成年、有力量且结构可信；面部有清晰眉骨、眼眶、颧骨与下颌，避免僵硬的玩偶脸。
装备遵循统一造型语言：有厚度的锻造板甲、合理的叠压与皮革连接，肩肘膝髋保留活动空间。大形清楚，装饰有主次，金属、皮革和织物能一眼区分。
用于MOBA 俯视战斗，兼顾英雄近景：优先保证缩小后的头肩、武器和披风轮廓可辨认。
先给完整正面设计，人物不裁切、武器完整，背景中性、光照平稳；设计选定后，再依据同一角色参考补齐侧面与背面，核对每件装备的位置和数量。
明确标出：脸部细节、甲片截面、披风连接、武器刃口与握柄。
避免：肢体/手指数目错误、融合的装备、浮空装饰、球形积木肩甲、通体同一种亮塑料、过度发光和大面积烟雾。
交付角色参考图，不宣称已经得到可绑定3D模型。

05 · 雕刻、拓扑与装备结构
工具/用途：Blender / 专业角色建模
交付物：可编辑高模与游戏网格、UV和烘焙记录
验收重点：检查中性灯光、无材质灰模、实际俯视三个视角；不得用细分掩盖结构问题。

重制“赤霄”的人物资产，保留设定、双手重戟和暗铁、旧金、深红。先备份已有角色，在独立版本中工作，先读取场景结构再修改。
人体：建立可信的胸廓、骨盆、肩颈和四肢比例。脸部重做眉骨、眼眶、眼睑、鼻翼、唇体和下颌的体积关系，让头颈和头盔自然衔接。
装备：胸甲贴合胸廓；肩甲通过结构连接而非悬浮；肘膝有活动余量；战靴分段且内部闭合；武器有真实截面、刃口、握柄与平衡关系。控制装饰的主次。
先以灰模检查大形，再做游戏拓扑、UV和需要的高低模烘焙。关节位置要便于变形；清理重复面、内部冗余和破损法线。
按照预定设备预算制作，不盲目增加面数。保留同名武器挂点和资产比例；如需改变骨架合同，先列出对运行时的影响。
输出：中性灯光正/侧/背、实际游戏镜头、线框与UV检查、源文件以及具体未解决问题。

06 · 贴图绘制与材质导出
工具/用途：贴图绘制工具 + Blender
交付物：实际UV贴图、导出GLB与新导入检查
验收重点：检查纹理是否真正绑定到运行网格，不能仅看Blender节点中是否存在图片。

为“赤霄”绘制统一风格的游戏贴图，配色为暗铁、旧金、深红。用于MOBA 俯视战斗，兼顾英雄近景。
建立有主次的明暗和色块：脸部保留眼眶、鼻唇和下颌的体积；盔甲表现厚度、叠压与受力边缘；皮革较柔哑；披风是织物，褶皱有走向。避免所有表面同一种高光和随机铺满划痕。
按目标渲染方式设计颜色、粗糙度、金属度和切线法线。若使用风格化绘制明暗，明确其与实时光照的分工，避免重复加黑。
在当前glTF导出器支持的材质路径内连接纹理，检查色彩空间、法线方向、UV和切线；ORM打包说明：R遮蔽、G粗糙度、B金属度，未用通道按实际需求处理。
导出后独立新导入，核对运行网格、材质、嵌入图像及其尺寸。特别检查皮肤粗糙度是否真实进入GLB；不要将“有PBR贴图”写成质量已达标。
输出纹理、源文件、导出文件、材质对应表与正反例截图。

07 · 骨架、权重与双手握持
工具/用途：Blender 绑定 / 动画技术美术
交付物：可编辑控制骨架、变形检查、烘焙动作
验收重点：关节自然、骨长不拉伸；挂点和root规则必须与游戏一致。

为“赤霄”建立适用于双手重戟的骨架与权重。
先核对米制比例、+Y向上/+Z正面、地面零点和目标运行时合同。建立root、骨盆、脊柱、肩臂、手指与腿脚；为披风和长缨设置足够的可控层级。
检查肩、肘、腕、髋、膝和踝的极限姿态，修正塌陷和装备冲突。刚性甲片与软组织采用合适的权重策略。
让双手约束在同一根刚性武器上，保留HalberdGrip与HalberdTip等明确挂点，核对手掌朝向、握持间距和肘部弯曲方向。先摆关键姿势，再烘焙到导出骨架。
脚底接地要考虑腿长和可达范围；空中释放脚锁，落地再建立接触。不要用拉伸骨骼掩盖无法到达的落点。
每段动作单独保存，保留名称、时长、循环属性和接触帧。输出绑定文件、姿态检查和烘焙后的实际模型验证。

12 · 商业角色观感验收
工具/用途：角色美术 / 动画审查
交付物：有画面位置与动作时间点的质量反馈
验收重点：这是人可读的美术判断清单，不是自动打分证明。

请从实际画面审查“赤霄”，目标镜头为MOBA 俯视战斗，兼顾英雄近景，武器为双手重戟。
分别查看：中性灯光灰模、静态材质、360度转台、正常游戏尺寸、无特效跑步/重击、带特效实战。
逐项评价：
- 头肩武器的剪影与朝向是否清楚，比例和站姿是否符合角色性格；
- 眉眼、鼻唇、下颌与颈部是否有可信体积和眼神；
- 甲片有无厚度、连接、活动空间，是否仍像球体和圆柱拼装；
- 金属、皮革、布料、皮肤是否有明确表面差别，色块和明暗有无层次；
- 支撑脚、重心、腰胯、肩臂、武器的先后关系是否成立，命中后是否真正制动；
- 披风/长缨是否随动作滞后并回稳，重要动作是否被遮挡；
- 换朝向、缩小和放回场景后是否仍有辨识度。
反馈必须附截图位置或片段时间点、影响及具体返修对象。区分“技术错误”“美术质量”“个人风格偏好”。测试数、面数和PBR图的存在不能作为通过理由。

历史用户需求（会话摘录，不是外部模型调用日志）
从原帖出发
我们能用 Codex 替代 Fable，复现这套角色建模和动画流程吗？需要哪些工具和配置？
理解：首先问清工具分工、资产来源和可复现的交付。

要求完整解释
新建子项目 首先展示原来的效果，说明器技术原理，价值，可扩展方向，然后说说如何用一个实际的效果进行演示
理解：效果、原理、用途和演示需要连起来。

从样例转向游戏
这个效果不够好  换一个真实的能用到游戏中的好的效果为导向 然后直接完成所有后续
理解：能够旋转和播放动画，并不足以证明适合游戏。

确定重武器方向
参考吕布的重武器战士
理解：明确成年体型、重甲轮廓和重武器发力，制作原创角色。

要求精修
继续精修赤霄，现在低模感还是太重了。参考吕布，把脸部、盔甲材质、披风和重戟动作做到更接近游戏成品的质感，直接完成后展示实际战斗效果。   这里和原库的效果差距很大啊
理解：修改对象是角色观感，不能只报告骨骼、贴图和测试数量。

推进剩余实现
那就继续按这个优先级把剩下的优化和补充都做完，重点把脸部、盔甲和动作做到接近吕布成品的质感，完成后直接展示实际战斗效果。
理解：补齐材质导出、接触修正、LOD、连续战斗和实机录像。

指出品质差距
这里的人物给人很假的感觉，如果要达到真实的英雄联盟那种水平呢？
理解：重新识别瓶颈：结构、绘制和动画导演，而非继续加面数。

形成研究共识
也就是说   要想素材优秀 就得专门研究生成专门的人物素材？
理解：把人物资产制作独立研究，设置美术验收，再接回已有游戏。
