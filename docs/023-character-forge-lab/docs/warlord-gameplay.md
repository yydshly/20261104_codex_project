# 赤霄 05 · 重戟演武

当前为 05 精修版：重新雕形的成年脸部、兽面曲面叠甲、闭合分段靴、平整戟刃与既有 PBR 贴图进入同一角色工程，参见 [本轮精修记录](warlord-refinement.md)。右上角可检视英雄，演武时可切换俯视/近景战斗、播放速度和画质档。「看技能连段」仍使用同一套命中规则。

双击项目根目录的 `play-web.cmd` 可打开本地预览；启动器使用 `127.0.0.1:5222`，优先服务已有构建目录。也可按 README 的 Node.js 命令启动。

目标是一个能进游戏引擎继续开发的成年重武器英雄样例。英雄「赤霄」使用暗铁重甲、红披风和双手长戟；战斗采用固定俯视镜头，面对三名会追击、蓄力攻击和受击退让的戍卫。

参考重点来自[《王者荣耀》吕布官方技能页](https://pvp.qq.com/web201605/herodetail/123.shtml)：宽扫清场、护盾承伤和跳劈进场控制的分工。本项目制作原创角色和独立战斗数值；没有使用《王者荣耀》的模型、贴图、动作或音效文件。

## 演示顺序

1. 首屏看成年英雄近景：观察双手握戟、重甲轮廓、披风与长缨。点击「进入演武」，进入固定俯视镜头。
2. 等守卫靠近，按住 Q 看横扫范围，朝敌人松开。前摇后戟刃扫过敌人，伤害、硬直和击退一起发生；命中后获得短时间戟势强化。
3. 守卫脚下出现金色蓄力范围时按 E。护盾随身移动，受击扣除护盾；可以继续普攻，观察护盾数值和承伤提示。
4. 按住 R 并移动鼠标选择落点，松开施放。英雄先起跳再落地，圈内敌人受伤并离地，之后落回地面，地面留下持续战域。
5. 用普攻连段收尾。三名守卫全部倒下后，结算显示用时、有效命中、护盾承伤与剩余生命。T 可重新演武。

「看技能连段」走同一套战斗规则，按移动或技能键即可接管。

## 连战检查与实际录像

页面的「执行 120 秒连战检查」会持续运行普通战斗并重复开局，采集未裁剪的真实帧间隔、绘制调用、几何与纹理资源等样本。保持页面可见才能累计有效时间；切换画质、录像或其他干预会停止当前检查。检查完成后读取页面结果，不能把功能入口或自动测试数量当作设备性能结论。

「录制技能连段」使用浏览器 MediaRecorder 记录真实 WebGL 画面、当时的生命/护盾与伤害反馈，并接入游戏音效，结束后通过本机预览服务保存到工程 docs 目录并提供 WebM 下载；静态托管不支持保存时会明确退回浏览器下载。录像不是生成的视频，也不通过改写状态制造命中或胜利。浏览器不支持录制能力时会提示。

## Web 运行时接触与画质

骨骼动画与角色世界变换完成后，Web 对接地脚步应用两骨 IK，并针对躯干、肩部、腿部和武器的胶囊近似约束披风/丝缨骨链；随后再采样武器轨迹。这样可以处理烘焙动画之外的转向、进身和混合姿态。胶囊是运行时近似，不是逐三角形实时布料解算，也不能保证任意姿态、任意装备或所有插值时刻都不穿插。

画质按钮切换均衡、精细与流畅档；运行时根据档位选择实际简化几何 LOD，并调整渲染像素比。LOD 继续使用相同骨架、动作和材质，未把贴图缩放当作几何 LOD。最终几何规模与目标设备帧时间以本轮实际验收数据为准。

## 重量感的实现

视觉和规则使用同一个时间轴：三次普攻接触时间分别是 0.23 / 0.30 / 0.40 秒；Q 在 0.42 秒扫中；R 在 0.18 秒起跳、0.92 秒落地。前摇和收势期间限制自由改向，攻击带小幅进身。命中短暂停顿、低频冲击声、敌人硬直与位移共同传达力量。

武器拖尾读取 GLB 中 HalberdTip / HalberdGrip 的实际世界坐标。Q 扇形与 R 范围圈使用战斗规则的相同角度、距离和落点裁剪。伤害浮字仅由真正命中事件产生；空挥不会给敌人扣血。

守卫采用追击 → 锁定朝向蓄力 → 攻击有效帧 → 收势状态。玩家可走出范围、闪避、开盾承伤或用技能造成硬直；敌人死亡会播放动作，停止攻击并逐渐淡出。

## 工具和配置

- Blender 4.5 LTS / Python：在 CC0 成年人形基体上制作重甲、战戟、挂点、双手控制和烘焙动作，导出 GLB 与可编辑 .blend。
- Three.js 0.187：本地加载骨架动画、几何 LOD、脚底 IK、布料胶囊约束、战斗镜头、灯光、阴影、武器带状拖尾和技能反馈。依赖已随项目保存，无需 CDN。
- Node.js 18+：本地 HTTP 预览、纯战斗测试、资产结构验证与打包。前端不需要安装 npm 依赖。
- Godot 4.5+：独立的 `engine/warlord` 工程加载同一个 GLB，继续制作碰撞、角色控制、战斗和场景。已有旧版骑士工程继续保留在 `engine/godot`。
- Codex：负责文件修改、Blender 脚本、玩法代码、工具执行与验证编排。本次未调用 Fable、Tripo、Seedance，也没有建立 Blender MCP 连接。

基础人体与通用动作来自 [Quaternius Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html) 和 [Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html)，遵循 CC0。具体制作与许可见 [角色制作记录](warlord-art.md)。

## 可扩展方向与边界

这是可玩的原创风格化英雄与可编辑资产。布料采用烘焙骨骼运动，加上 Web 胶囊近似约束；尚未保证任意姿态的三角网格布料碰撞。当前手工雕刻、专属拓扑/绘制贴图与面部表演仍未等同《王者荣耀》商业吕布成品的精度。

下一阶段需要在目标游戏镜头和设备中继续评估手工贴图、面部表演、肩肘护甲形变、脚底 IK 在更多地形上的接触，以及技能衔接。原生 GPU 画面和物理手机尚未实测；headless 检查不替代 GPU、触屏或人工手感验收。联机需要服务端权威命中与状态同步；Unity/Unreal 需另做导入、材质和动画重定向验收。

最终运行记录见 [浏览器验收记录](warlord-browser-verification.md)；原生自动检查保存在 `engine/warlord/validation`。自动检查证明规则和数据约定，动画观感仍以实际画面为准。
