# EMBERFALL · 遗迹试炼

这次的目标是一个可直接操作的第三人称动作关卡。首页为游戏，初版原理展示保留在 `study.html`。

## 操作与目标

WASD / 方向键移动，Shift 奔跑，J / 左键攻击，空格闪避，F 格挡，鼠标右键拖动视角，滚轮调节距离。Esc 暂停，R 重试。触屏提供移动方向与挥剑、闪避按钮。

靠近并击破三座回响水晶。每座有 100 生命，会在玩家靠近后蓄力发出冲击。预警阶段出现地面光圈，空格闪避的动作窗口提供无敌帧，格挡消耗体力降低伤害。三段剑击需要连续输入，伤害分别为 18 / 18 / 30；一次攻击只会触发一次伤害。

「观看完整试炼」使用与手动操作完全相同的移动、碰撞、体力、攻击和伤害逻辑。它会靠近目标、连击与闪避，不能直接修改生命或跳过胜利条件。任意移动键、攻击或闪避输入均可接管。四种步长下的核心模拟均能通关，实际浏览器耗时也包含命中停顿等表现。

## 真正完成了哪些环节

- 专业游戏角色：KayKit 官方免费 CC0 骑士。作者 Kay Lousberg，基础模型、贴图、骨骼和动作均保留来源，不称为自建或 AI 生成。
- 资产整理：去除重叠装备，保留右手剑与左手盾；比例规范到含羽饰高 1.85 米，前向 +Z，地面 0；统一 16 个动作名称，清理根 XZ 漂移，由控制器处理世界位移。
- 游戏接入：动作状态机、混合过渡、碰撞、生命、体力、三连击缓冲、攻击扇区与伤害窗口、闪避位移与无敌帧、格挡、冲击波、胜负与重置。
- 场景表现：独立程序化暮色森林圣所，石板、遗迹、草木、火盆、雾、阴影、水晶和微尘。剑光、火花、伤害数字、短暂命中停顿和过程生成音效由游戏事件驱动。
- 引擎交付：同一角色 GLB 进入 Godot 4.5.2，原生场景能移动、战斗、胜利、死亡、重置。19 项 headless 真实运行检查通过，独立项目 ZIP 解压后重新导入并复测通过。

## 已执行检查

浏览器控制器的 20 项 Node 测试：移动与碰撞、单次命中、距离与攻击扇区、明确输入三连击、体力、闪避、格挡破防、受击保护、冲击预警、死亡重置、胜利唯一事件、4 种步长自动通关。

角色资产验证见 `assets/game/asset-validation.json`：41 骨骼、10 网格、5,274 三角面、16 个有实际变换的动作，贴图内嵌，权重归一，关节索引有效。Blender 已导入并渲染待机、奔跑和攻击；FBX 已重新导入验证。

原生检查详见 `engine/godot/validation/gameplay-report.json`。根目录 `npm run verify` 会重新检查核心逻辑、游戏资产与交付文件。

## 可用范围

这是一套可继续开发的单人动作关卡与角色接入工程。它没有调用 Tripo / Seedance，也没有宣称复现原帖的付费生成流水线。KayKit 的 Dodge 是作者制作的闪步躲闪，不是翻滚。Blender 工作文件是免费 GLB 导入整理后的衍生文件，不是官方付费 SOURCE 档。Godot 原生工程已运行验证；Unity 和 Unreal 未在本机验证。

## 文件位置

- `src/game.js`：渲染、输入、动画、音效、HUD、反馈。
- `src/game-logic.js`：可测试的移动与战斗规则。
- `src/game-environment.js`：本地构建的遗迹训练场。
- `assets/game/hero.glb` / `.fbx` / `.blend`：整理后的游戏资产。
- `assets/game/character.json`：动作名、比例、挂点和来源。
- `engine/godot/project.godot`：原生工程。
- `docs/asset-provenance.md`：许可与处理记录。
