# 赤霄 V5：可见造型、材质与动作加工

V4 为原低模基体增加了曲面和真实贴图，但圆球肩甲、球形膝甲、方块靴及基础五官仍限制了观感。V5 直接修改这些可见形体，并继续处理动作中的接地、握持和布料间距。更换工作流编排工具不会自动补足角色设计与制作投入，原库和商业角色之间的视觉差距仍需在资产本身解决。

## V5 已完成的美术加工

**脸部与颈部。** 在已有成年头部和蒙皮上雕出更明确的眉骨、颧部、鼻梁/鼻翼及下颌角，调整颈部体块。皮肤贴图重新绘制了肤色、眼窝、颌部与闭口变化，保持克制的皮肤反射；窄眼和虹膜处在同一可见眼面内。颈下原先可见的锯齿材质分界移入衣领遮挡区。

**曲面叠甲。** 球形肩罩换为有尖锐外展护缘的曲面冠板、错层甲片和薄金属包边。兽面纹样具有实际嵌板、眉眼、鼻脊和颊部浮雕，配合铆接点形成统一的装配语言。护膝换为尖形中脊甲，胫甲沿小腿收束；完整闭合的皮靴内胆支撑五段重叠弧形足甲，修正空心甲片和方块鞋头。

**战戟与材质。** 主刃、反钩和枪尖改为平整面与薄磨削带的真实截面，保留同一刚性武器和既有挂点。主护甲、红布及皮肤继续使用图像 PBR 贴图；本轮重绘现有皮肤和刃面贴图，减少粗网纹和过强表面噪声。暗钢、黄铜、皮革、织物与皮肤的反射分工分别保留，没有通过增加贴图数量掩盖造型问题。

以上改动保存在 `assets/warlord-v5/art.blend`，阶段报告 `art-report.json` 确认仍为 **100 骨、13 动作**，输入工程的图像总数未增加。工作预览 `art-three-quarter.png`、`art-front.png`、`art-face.png` 是 Blender 真实渲染；它们用于造型目检，不替代浏览器中的战斗画面。

## 动作、披风和验证范围

角色沿用人体与武器 70 根骨、披风 20 根骨和丝缨 10 根骨的层级。披风使用连续褶皱曲面、内衬、包边和多链骨驱动，丝缨另有骨链；这是烘焙的二级动画。它不等于对任意环境、任意速度都会成立的实时布料模拟。

13 个动作的时长与玩法接触时间保持既有合同。双手重新约束在同一刚性戟柄上，动作包含腰胯蓄势、重击收势和落地压身；游戏仍负责世界位移与跳跃弧线，局部骨骼变化不重复叠加角色 root 位移。

V5 制作阶段的 `animated-final.collision.json` 记录了如下实际检查：

- 从真实网格顶点、蒙皮权重、骨骼姿态和逆绑定矩阵计算变形几何，而非仅看骨骼或包围盒。
- 对闭合的人体、护甲和武器表面建立几何采样，统计报告列出的离散姿态中披风顶点的有符号距离；报告中的“穿入”阈值为超过 2 mm。
- 为镜像的封闭碰撞几何校正朝向；开放饰线、贴片和没有内部体积的装饰面单独列出，不把它们当作封闭实体判定内外。
- 检查各动作的双腕与戟柄距离、接地踝部漂移，以及 Walk / Run 的步幅估计，供运行控制衔接使用。

这些结果覆盖报告列明的输入姿态、几何和阈值。它们不能证明任意两段动画混合、任意装备、所有插值时刻或目标设备运行时都无穿插。最终 GLB 需要重新检查，实际脚部接地、动作混合、布料和武器反馈还应在游戏中验收。

## 复现与文件分工

V5 的造型脚本 `sculpt-warlord-v5.py` 读取已经接受的 V4 100 骨工程，输出 `assets/warlord-v5/art.blend`；随后由 `motion-warlord-v5.py` 串联动作与布料校正。它不是对 V4 表面脚本反复叠加细分。后续运行网格合并、LOD、纹理打包与最终导出属于独立交付步骤，最终资产仍放在 `assets/warlord`。

原始 CC0 基体、许可及 13 动作时序见[角色制作记录](warlord-art.md)。造型中间工程与最终运行资产分别保留；在交付包中是否包含全部中间工程，以包清单为准，不把本机工作文件路径当成已分发的文件承诺。

## 当前质量边界

赤霄是原创、风格化的独立游戏角色，参考吕布式重甲英雄的气质、轮廓和重戟技能分工。项目没有导入《王者荣耀》的商业角色资源，也没有把本次输出描述为商业吕布手工成品的同等替代。

与成熟商业英雄相比，角色专属雕刻、手工拓扑、皮肤与护甲绘制、真实布料接触、面部表演和完整动作导演仍有差距。本轮没有复现原帖中 Tripo 资产生成与 Seedance 动作生成的整条链路。对“接近成品”的判断应看真实战斗镜头中的轮廓、表面、动作和性能，不能只看工作室灯光渲染或增加的面数。

实际浏览器证据与运行结果见[浏览器验收](warlord-browser-verification.md)。
