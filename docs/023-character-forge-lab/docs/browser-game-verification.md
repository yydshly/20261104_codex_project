# 浏览器实玩验收 · 2026-11-12

本轮在当前内置浏览器实际载入 `http://127.0.0.1:5220/` 的生产构建，检查了新的 EMBERFALL 游戏。

## 已观察到的实际结果

1. 专业角色、内嵌贴图、剑盾与森林遗迹场景正确载入；开始按钮在资源载入完成后启用。
2. 点击「观看完整试炼」，通过真实游戏控制逻辑完成三座 100 HP 水晶：**19.4 秒、15 次有效命中、3 次闪避、剩余生命 100**。界面显示 3/3 和「圣所已苏醒」，截图保存在 `docs/game-victory.jpg`。
3. 点击重试能重新进入进行中的试炼，观察到第二次已击破 2/3 水晶，并继续奔跑寻找最后目标，预警环与剩余目标血条同步。
4. 手动开始后，使用真实键盘 W 持续输入，角色进入 Walk 并在场景中前进；再次靠近后输入 J，状态进入 Attack1，体力从 100 降到 92，并出现 18 点伤害数字。
5. 靠近水晶后遭到真实冲击，生命由 100 降到 82，红色受击反馈、受击提示与波纹显示。
6. 开始时的页面滚动已修正为回到游戏顶部；游戏 HUD 与目标可在当前桌面视口内显示。

## 已修正的接入问题

- 重试同步重置连击显示为 01。
- 长按 R 不会反复重启。
- AABB 精确边缘重叠会正确推出碰撞体。
- 体力不足时格挡会破防并进入 Hit。
- 完整交付包包含运行 `npm run verify` 所需的 tests 与验证脚本。
