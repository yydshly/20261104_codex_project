## 最终资产和动作

100 骨、13 动作，实际人体约 2.047 米。高精 266,728 三角面，28 个 mesh 节点、29 个 primitive；高精保留全部原始三角面。LOD1 为 97,638 面，LOD2 为 43,299 面；二者仅存几何，共享高精骨架与材质。披风与丝缨的顶点、三角面、权重在 LOD 中完全保留。

高精 GLB 为 19,074,680 字节；两份几何 LOD 合计 10,327,448 字节。需区分单个角色文件大小与网页加载总量，场景和引擎代码另计。五类主材质均确实使用 1024² 颜色图和 512² 法线/粗糙度金属度图；JPEG 颜色压缩及 PNG 数据图不等于 KTX2 显存压缩。

最终导出保留全部 3,900 条动作通道的输入时间、数值和插值，未简化已校正的 100Hz 布料关键帧。真实闭合身体、护甲、武器与布料外表面顶点的检查覆盖 13 动作共 1,300 帧，报告中的最小正间隙约 1.05 mm。该结果不能外推任意混合姿态、布料厚壳、开放饰片或任意装备。运行时补充身体、腿与戟的胶囊近似约束，并处理脚底锁定、进身重植及空中释放。

证据：`assets/warlord/validation.json`、`collision.json`、`material-validation.json`、`optimization-validation.json`、`optimization.json`，以及保留的逐帧检查基线/未改动作指纹。

## 交付和边界

Web 规则、集成、脚锁与真实连段测试共 56 项通过。Godot 4.5.2 的玩法 43 项和骨骼约束 16 项通过；自动 LOD 已启用。精确原生源码 ZIP 已在没有 `.godot` 缓存、没有外置纹理的新目录中真实导入，重建 25 张纹理，并核对 100 骨、13 动作、五类真实 Texture2D PBR 材质和运行代码 SHA；见 `engine/warlord/validation/sourcekit-fresh-import.json`。

浏览器窄屏只验证 390×844 的布局及可见技能按钮，未冒充物理手机或触控精确落点测试。Windows headless 未提供原生 GPU 显示上下文，Godot 检查不能替代原生画面与 GPU 性能。Unity/Unreal 导入、联机、面部表演和任意姿态布料解算不在已验收范围。

角色有实际可玩和可编辑的工程，但仍是原创风格化独立游戏角色，不能据此声称与商业吕布英雄成品同等品质。
