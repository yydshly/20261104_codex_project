READABLE WEIGHT · DISTINCT ABILITIES

重武器的感觉，来自每一招的作用。

出手前看懂范围，命中时看到身体反馈，收势后决定下一步。对手会靠近和反击，需要用技能创造时机。

Q / CLEAVE

破阵横扫

腰胯带动双手战戟，蓄势后宽幅扫过前方。命中可硬直多个敌人，并获得戟势强化，影响接下来的普攻。

蓄力 → 刃扫命中 → 进身收势
E / BULWARK

铁壁护身

在敌人接近时吸收战意形成护盾。开盾期间可以走位和攻击，用护盾顶住反击，争取下一次横扫。

近敌成盾 → 承伤 → 继续进攻
R / LEAP SLAM

坠星裂地

先选择落点，再蓄力跃起，重戟随身体砸落。落地造成范围伤害与击飞，战域让进场和站位更有意义。

定落点 → 起跳 → 砸地 → 击飞
