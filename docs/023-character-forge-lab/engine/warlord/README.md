# 赤霄 · 重戟战将 · Godot 原生 MOBA 试炼

独立于旧 `engine/godot` 工程。本工程采用成年强壮人形、原创重甲和长柄战戟，固定高俯视镜头，并实际实现三普攻、技能和敌人 AI。

## 精修角色资产

当前工程使用与网页精细档完全相同的 V5 canonical GLB：`1f3fc19564ebfd7bf1ae8e9c27ed9f3e041c55bfde18f1c43f35e4bab2ea7838`，19,074,680 字节，28 个合批网格、100 根骨骼、266,728 个三角面，保留 13 个可玩动作。20 根披风骨链与 10 根丝缨骨包含烘焙二级运动，不依赖 Blender 布料模拟。

ArmorDark、ArmorGold、Blade、ClothRed 与 HeroSkin 五种主材质均包含真实的 1024×1024 基础色、512×512 切线法线与金属/粗糙度贴图；25 张图片嵌入 GLB，所有使用这些主材质的网格都有非恒定 UV。新版面部、连续曲面护甲、倒角与披风褶皱属于资产本身，可随 GLB 进入引擎。

Godot 的 `assets/warlord.glb.import` 已启用 `meshes/generate_lods=true`，由原生导入器生成其自身 LOD；工程不读取网页的独立 geometry-only LOD 文件。该配置已在最终 headless 导入报告中核对，原生 GPU 上的实际 LOD 选择与帧率仍未人工验收。

网页与 Godot 使用各自的灯光与环境设置。此次原生检查仅验证导入、蒙皮、动作、玩法和物理；原生 GPU 下的反射、材质观感与性能仍需人工验收，不能由 headless 结果推断。

V5 原生运行时增加 `SkeletonModifier3D` 后置约束：在 AnimationMixer 播放之后做世界坐标脚锁、重击进身抬脚/重植，以及披风/丝缨骨对身体和戟柄的 capsule 补避让。R 的 0.18–0.92 秒腾空段与被击飞状态释放双脚，步态读取实际动画播放时钟。Godot 的 modifier 栈在更新 skin 后恢复原始姿态，避免每帧约束叠加；胶囊只补充混合动作的安全边界，不等于全网格无穿插保证。

## 运行与验证

使用 Godot 4.5+ 打开 `project.godot`。在当前工作区可以双击 `play.cmd`；该脚本先查找已有的官方便携引擎，再查 PATH 中的 Godot。它只设置子进程的本项目数据目录。

本轮开发与验证严格只用 CLI/headless，没有启动可视窗口或操作 UI。`verify.cmd` 会重新导入素材并执行原生玩法与 secondary 约束检查。自动报告位于 `validation/gameplay-report.json` 和 `validation/secondary-report.json`。`scripts/offscreen_capture.gd` 已确认本机 Windows headless 不具备原生 GPU 帧捕获能力，详见 `validation/offscreen-probe.json`。

最终交付已在官方 Godot 4.5.2 中完成 **43/43 项玩法检查与 16/16 项后置约束检查**，覆盖最终模型、13 段动作、胶囊物理、三连击时窗、Q/E/R、敌人追击与预警、击退击飞、胜负重置，以及真实脚锁、动画倍速、可达落脚点和约束姿态恢复。两份报告同时绑定最终 GLB SHA-256 与运行时代码 SHA；headless 通过不代表原生 GPU 画面已验收。

运行 `package-source.ps1` 可重新生成 `engine/Warlord-Godot-sourcekit.zip`。打包器核对当前 GLB、metadata、PBR 报告与两组原生报告，以及运行时代码哈希，再按白名单打包工程；不包含引擎 exe、`.godot`、`userdata`、日志或从 GLB 提取的重复图片。首次导入会从嵌入 GLB 重新生成所需纹理；工程不需要工作区旧缓存。

## 操作

| 输入 | 行为 |
| --- | --- |
| WASD / Shift | 移动 / 奔跑 |
| 鼠标 | 地面瞄准与 R 的落点 |
| 左键 / J | 重戟三段普攻，可在动作中缓冲下一击 |
| Q | 155° 宽扫，命中后强化普攻 |
| E | 护盾，可继续移动；近敌额外增加护盾并减速敌人 |
| R | 最远 5.5 米的定点跳劈，落地 3.2 米 AOE 与击飞，留下领域 |
| 空格 | 短闪避 |
| T / F5 | 重置整场试炼 |

三名敌人会追击、锁定方向预警、攻击和收势。受击会进入硬直、击退或击飞；生命耗尽播放死亡动作。击倒三人即胜利，英雄死亡则失败。

## 规则

- 英雄生命 240，敌人各 140。
- 三普攻总时长 0.72 / 0.82 / 1.00 秒，命中时间 0.23 / 0.30 / 0.40 秒，基础伤害 22 / 26 / 38，分别带 0.22 / 0.32 / 0.42 米进身。
- Q：1.08 秒动作，0.42 秒命中，3.35 米范围、155°，58 点伤害，4.8 秒冷却。命中后六秒内普攻增伤并少量回血。
- E：基础 90 护盾、四秒持续、六秒冷却；附近多名敌人增加护盾并触发减速。
- R：1.28 秒总动作，0.18 秒起跳、0.92 秒落地，5.5 米施法距离、3.2 米 AOE，76 点伤害，九秒冷却。腾空阶段由控制器统一设置高度，避免动画与控制器重复加高。
- 敌人：追击 → 0.58 秒预警 → 0.16 秒攻击 → 0.6 秒收势。伤害与命中方向在窗口内计算，不依赖视觉特效。

核心参数参考根项目的 `src/warlord-logic.js`，移动、碰撞、击退和击飞由 Godot CharacterBody3D 物理独立执行。

## 主要文件

- `scripts/combatant.gd`：角色/敌人状态、动画调速、普攻与技能、生命护盾、物理位移。
- `scripts/arena.gd`：固定相机、战场、AI 交互、范围命中、VFX、技能 UI、胜负与重置。
- `scripts/smoke_test.gd`：实际 Godot 中的资产、动画、时窗、范围、AI、物理和胜负验证。
- `assets/warlord.glb`：最终战将资产的独立副本；来源和许可随素材保存。

本工程可导入和继续编辑；headless 检查不等于原生 GPU 画面、操控手感或性能的人工验收。本轮不会把未进行的可视验收标为通过。
