# 《风吹信封》AI 视频工作流复现

这次用同一个 5 秒镜头，分别测试短提示词、加首尾帧、再加结构化提示词。三组共用故事、时长、画幅和模型。镜头内，右窗进风，先吹起窗帘，再把桌面唯一一封信从画面右侧推到左侧。邮差最后转移视线，双手始终放在扶手上。

## 最后形成的理解

本轮最值得保留的是付费前的输入图检查和局部合成。我们实际找出并修正了四处本不该变化的固定区域。像素差值归零描述静态输入图，视频质量、成功率和返工节省仍需另测。

A 只用短提示词，已经生成了窗帘先动、信封再滑、停稳后人物轻微反应。B 加首尾帧后，人物、机位和道具起止更贴近分镜，动作起动却更接近同时。C 沿用同一对帧，改用七段式提示词后，两次起动拉开约半秒，但人物提前追看并多出斜光。

三组各一次且未固定相同随机种子，B 到 C 又同时扩写了多种要求。这里保留三个样本的实际表现，稳定的提示词收益、跨镜头一致性和整片省时省积分仍待验证。第 7、8 步本次仅完成并排剪辑和单镜头复核。

## 原文流程和工具分工

| 步骤 | 操作和产物 |
| --- | --- |
| 1. 定故事 | 导演与人确认故事和制作条件，用一句话说清镜头表达的内容。独立审核者只读故事，先复述理解，再指出因果漏洞和难拍动作。 |
| 2. 写分镜 | 写清景别、机位、画面方向、运镜、动作起止和转场。先定配色，再出正式图。 |
| 3. 定画风与角色 | 用设定图锁定人物、服装和固定道具。导演负责组织任务，Codex 负责静态图。 |
| 4. 做首尾帧 | 先写清首态、尾态和中间的变化，再画图。首帧提前摆好会用到的道具，叠看两帧来查固定物件是否漂移。 |
| 5. 写提示词并复核 | 按画风、镜头、构图与配色、人物、分段动作、声音、约束组织。独立审核者对照文字、图片和设定，人确认预算。 |
| 6. 生成 | 先测最难的正式镜头。Seedance 根据输入生成动态，保留原片和各次尝试。 |
| 7. 后期 | 用 FFmpeg 和 Python 做剪切、拼接、转场和调色。将时间点视为动作编排，精确节拍在剪辑时处理。 |
| 8. 复核 | 给独立审核者看成片，让其先复述故事，再按时间标记问题。人确认播放节奏和声音。 |

原文用 Claude Code 做导演，也允许 Codex 代任。本次 Claude Code 的登录令牌已过期，实际由 Codex 做导演，调用内置 ImageGen 做图，用 FFmpeg 处理固定区域。视频环节走用户选定的 ChatArt。原文还提出由不同角色负责制作、审核、核对用户要求和预算内决策。 [Eian 的 X 原文](https://x.com/i/article/2118298893238845441)

最容易迁移的是几条镜头写法。方向以画面为准，并加桌沿、门框等地标。动作要写出原因和先后，比如先让帘角向左扬起，再让信封沿同向滑动。需要动的道具提前进首帧，需要持续保留的特征出现在两帧。单镜只承担一两个主要动作，时间段用来表达顺序和节奏，精确卡点留给剪辑。先检查模型输出，再决定是改提示词、修参考帧，还是用后期解决。

## 本次实验和前置审核

| 组别 | 提交给模型的材料 | 对照目的 |
| --- | --- | --- |
| A | [短提示词](A-short.txt) | 一次纯文本生成作为基线 |
| B | 同一条[短提示词](A-short.txt)和[首帧](first.png)、[尾帧](last.png) | 与 A 比较加入首尾帧的差异 |
| C | [七段式提示词](C-structured.txt)和 B 的同一对首尾帧 | 与 B 比较动作、空间和约束写得更具体时的差异 |

三组统一使用 ChatArt Seedance 2.0 Mini，5 秒、16:9、720p。图生视频脚本会忽略静音开关，所以实际提交的三组统一开启音频。三组各提交一条，保留未剪辑原片。预计 60 积分一条，共 180 积分，实际用量以生成结果为准。 [导演任务](director-brief.txt) · [角色参考图](character-reference.png) · [首尾帧并排预览](frames-side-by-side.png)

独立审核先指出风向在画面和文字里要明确，因此写进了窗帘朝画面左侧扬起、信封随后左滑的动作顺序。先生成[原始尾帧](last-generated.png)，再参考它局部编辑出[原始首帧](first-generated.png)。编辑后头发、手和桌面也发生了变化，于是只取眼睛和信封所在的区域，合成到尾帧的固定画面上，作为最终首帧。

## 视频结果与价值判断

A（1051085）、B（1051082）和 C（1051086）均已完成，原片均通过解码检查。每条任务返回 75 积分，共 225 积分，高于提交前预估的 180 积分。A 和 C 原片为 1280×720、约 5.088 秒，B 原片为 1344×768、约 5.175 秒。三条均为 24 fps 且含音轨。[三组并排视频](chatart-results/abc-comparison.mp4) · [同步抽帧](chatart-results/abc-contact-sheet.png)

| --- | --- | --- | --- |

**A 对 B。** 同样的短提示词下，B 把人物、机位和信封起止位置拉回预设参考画面。A 自行决定了这些视觉细节，也成功表达了窗帘先动、信封再滑。首尾帧在本次样本中主要体现出对画面和起止状态的约束。

**B 对 C。** 同一对首尾帧下，C 把窗帘和信封的起动错开了约半秒，人物反应也更丰富。信封停稳前人物已开始追看，开头新增的斜光也偏离了保持光线稳定的要求。分段写法能明确动作目标，仍要用成片检验执行情况。

每组只生成了一条，生成请求也没有锁定同一个随机种子。这些观察描述本次三个样本，适合用来决定下一次重点查什么。成功率和平均返工成本需要更多样本。
