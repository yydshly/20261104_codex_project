# 小样观看反馈表

先不告诉观看者创作意图，让对方看完，再记录原话。用少量反馈发现具体问题，不把它推成普遍结论。

## 2026-11-21｜海洞 8 秒小样 v1

- 素材：`episodes/cave-welcome-8s/renders/cave-welcome-8s-v1.mp4`。
- 用户原话：**“看起来没啥内容啊”**。
- 创作判断：片中只有抬眼、微笑、拉椅、等待；拍摄者为什么来到这里、为何值得停留、人物关系怎样改变均未呈现。人物动作测试已经做出，但这个结果不能证明短片内容具有吸引力。
- 下一版首要修改：恢复“普通送达 → 稀有空间 → 准备离开却被挽留 → 发现自己是被等待的人”的完整事件，见 [15 秒故事修订](08-cave-story-revision.md)。
- 证据边界：用户没有指出具体秒数或技术问题，不推断其已认可人物、真实感或画面质量。修订是待观看验证的创作方案，未生成新视频。

## 分阶段提问

看氛围图时，询问空间、人物关系和第一感受；不要让静帧承担动作是否成功的问题。

看最难镜小样时，询问机位、遮挡、动作因果、身份与空间是否连贯。

看完整短片时，再检查开头是否引出问题，中途是否出现新的期待，结尾是否完成这条情绪主线。

把“感觉像真的”和“认为确有其事”分开记录；前者评价视觉与叙事，后者涉及素材的事实身份。本项目的新故事均是虚构创作。
