# 实时池塘 v4 验收

日期：2026-11-12。本次只升级实时三维呈现，运行入口为 `http://localhost:5217/`。

## 自动与结构验证

- `npm run check`：页面、场景、材质、照明、水、鸭子、音频和服务脚本语法通过。
- `npm test`：一次呼唤只触发一次叫声；300 秒连续游动保持池岸约束；整只鸭子的 0.92 半径包络与码头矩形保持距离；暂停冻结位置。
- 水面超过 5,000 顶点，尾流保存航向，静止不生成尾流；暂停时短水纹和尾流仍可消退，持续水面和浮高采样保持冻结。
- 鸭子跟随外部水位采样，资源支持重复释放。
- 风速通过积分推进波相位；单独模拟运行一小时后改变风速，下一帧只前进约 .01114 秒波相位，没有历史时间重缩放。
- 12 张扫描材质校验官方 MD5 和本地 SHA-256，HDR 校验 SHA-256；来源与许可记录在本地清单。

## 实际浏览器检查

在 Codex 内置浏览器检查默认画幅、1280 × 720 横屏和 390 × 844 竖屏；竖屏使用更高的取景角度，避免大量空天空。临时画幅覆盖已恢复。

- HDR 成功载入，画布 `data-lighting=hdr-ready`。最终版本无控制台错误或警告。
- 暮色/夜晚均完成真实 GPU 渲染。木纹、石面、树皮、林坡、分离叶片、连续鸭身和水面倒影可见。
- 呼唤检查观测到 `duckPhase=quack`、`quacks=1`、`lastSoundPlayed=true` 和 `audioReady=true`；随后游近。关闭声音后按钮保持 `aria-pressed=false`。
- 水面点击触发 `interaction=water`，随后出现“它游过来了”的到达提示。
- 阵风期间观测到风值从 .300 上升至 .562，再回落。
- 暂停前后独立采样，鸭子位置和 simulationTime 均完全不变，状态为 paused；恢复后继续游动。
- “隐藏面板/显示面板”、退出/进入场景有效，隐藏面板时保留画布交互。

## 渲染与质量边界

- 环境 29 个网格批次，鸭子 16 个网格，水面 10,800 三角面。浏览器完整帧约 152 次绘制、232 万三角面，包含阴影、反射和后处理，不等同于静态模型预算。
- 接触阴影直接读取主渲染真实深度，避免独立法线通道遗漏叶片/鸭身变形，也避免重复绘制整张阴影图。手机宽度下关闭 AO，保留反射和主灯光。
- 这是本机浏览器验收，未以单次帧率读数作为跨设备性能保证；尚未在实体手机上测量。
- 当前为自制风格化实时模型与扫描表面材质，并非影视级雕刻/完整流体模拟。未能重新取得原始 X 视频做逐帧对照，因此不宣称已验证与原作同等画质。
