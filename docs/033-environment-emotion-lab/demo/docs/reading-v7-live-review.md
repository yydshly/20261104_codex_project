## 第一轮实际证据

目录：`reading-v7-live-review/review-20261115062231010/`。

- 收到了实际 GPU 场景的 `01-seated.png`，以及位置、视角、渲染帧率与音频状态。
- 记录中 GPU 着色器错误数为 0；这只能说明已执行部分没有报告编译错误。
- 初始坐姿画面被椅子近处结构挡住大半，不能作为合格的阅读视角。
- 热身阶段记录到约 90–108 帧/秒，随后持续约 1 帧/秒；计时器仍定期执行、场景只按很少的渲染帧前进。该变化符合预览失焦降频的表现，尚不能仅据此判断 GPU 性能。
- 在出门前超时；声音仍为关闭状态，电平为静音。**这一轮没有完成实际往返和听感验收。**

## 已修复

- 眼睛位置抬高并前移，视角按真实书本坐标计算，避免原来的固定视角与椅子结构冲突；修后画面已检查。
- 起身和坐下的位移延长为平滑过渡；坐下朝向连续插值。
- 自动步行、到达池边时限制转向速度，转弯时适当减速；程序检查确认往返过程中没有视角突跳。
- 声音诊断与录音从最终压缩器输出采样。
- 验收页记录焦点，支持点击开启声音后继续当前测试，并在重试前返回座位；测试失败会停止自动路线。
- 临时本机验收服务支持项目依赖变更后的自动刷新，后续修改无需反复打开其他浏览器。
- 转弯提前看向后续路段，门外前景与远景补齐；保留两款现成树形，以十二棵实例围合庭院。
- 取图时保存对应的实际相机位置与时间；庭院和门口的取图不再因等待上传而错过。
- 验收专用补帧应对内置预览失焦时停止 rAF，普通体验仍沿用正常绘制方式；本轮采集不是设备帧率基准。
