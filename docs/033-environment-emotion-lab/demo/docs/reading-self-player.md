# 自己控制的主体人物与双视角 · 2026-11-15

本轮根据用户反馈，将重点从陪伴人物转回“自己在环境中活动”。当前运行时移除独立陪伴人物、招呼按钮与对应碰撞，保留茶桌、摇躺椅、脚凳和遮雨棚。同一套通用人物素材改为玩家身体。

## 操作

- 顶部“视角”按钮或 **V** 切换第一 / 第三人称。两种视角共用一个人物位置与动作，不切换场景。
- **WASD / 方向键** 控制移动，拖动环顾；触屏保留方向按钮。手动方向输入会接手自动步行。按 **E** 与近处物件交互。
- 可以起身、沿小径走到池边或茶角、靠坐喝茶、回房坐下。行走与靠坐期间也能切换视角。
- 顶部“收起操作”可隐藏底部面板，保留视角按钮、环顾和键盘控制。

## 实现

`reading-walk.js` 负责人物眼位、朝向、路径、碰撞与坐下 / 起身进度。起身先抬起身体再移动；坐下先走近再降低视点。它不再直接拥有最终渲染相机。

`reading-camera.js` 将渲染相机与人物分离。第一人称使用人物眼位；第三人称使用略偏肩后的跟随镜头，保持同一观察方向。切换时平滑过渡。相机臂对墙、房门、家具、树干、屋顶与棚架的简化三维实体做遮挡检测，遇到障碍立即收近，离开障碍再渐渐拉远。相机不参与人物碰撞，也不把人物带过墙；水面允许相机越过。

`reading-player.js` 复用完整蒙皮人物与原作者 Idle / Walk 骨骼动作，按实际位移速度调节步行动画，身体随移动方向转向。室内坐姿与室外靠坐使用运行时双骨骼 IK 适配腿脚和手臂，恢复动画原姿态后再计算，避免变形积累。喝茶时一侧手臂抬向面部，杯子使用同一只手的世界坐标作为动作目标。

第一人称隐藏靠近眼位的头部表面，保留身体和手脚，避免从模型脸内向外观看；第三人称显示完整身体。头部隐藏只影响贴近眼位的相机，保留远处水面反射与原有投影逻辑。人物进入房间或庭院时使用对应光照层。

声音的空间锚点仍来自人物眼位，第三人称镜头收近或切换不会把雨声、池塘声和 MiniMax 书页朗读的位置带走。保留自然录音、随机鸭叫、静音和位置淡变。

## 验证与边界

程序检查覆盖真实 GLB 蒙皮与行走、人物位移、第一人称头部遮挡、坐姿 IK 稳定性、喝茶手部目标、切换不改变人物眼位、墙与开 / 关房门的相机遮挡、茶角往返及原有空间音频回归。实际 GPU、界面和双视角往返另用内置浏览器验证。

当前是可控制人物与双视角的场景实现。相机遮挡使用简化实体，坐姿适配不是新的动作捕捉；没有完整手指抓握、通用攀爬跳跃或复杂地形步态系统。


本轮已完成语法、真实模型 / IK / 相机和原有声音回归检查。内置浏览器实际观察到室内坐姿、第三人称从房间走到池边、第一人称回切，着色器错误为 0；浏览器工具在后续茶角检查时中断，因此最终茶角双视角画面与全程主观听感未完成新一轮验收。随后按模型眼骨实测将茶角靠坐眼高校准为 1.48 米，已增加眼高一致性断言。
