# 坐姿、视角与室内拿书修复

用户的室内侧面和户外背面截图暴露了上一轮遗漏：室内拿书没有接入，落座使用较远的固定站位，人物姿势与座椅实际网格没有充分校准。上一轮的户外持物与往返记录不能替代这些检查。

## 本次修正

- 室内落脚点从 `(1.34, 1.70)` 改到椅前右侧 `(0.02, 1.08)`；在附近按坐下直接进入落座，不再先走到远处再折返。动作期间拒绝重复切换，避免中途重新起身。
- 默认坐姿视线顺着座椅朝向，不再自动扭向侧桌。第一人称镜头使用左右眼骨骼的实际中心，随坐姿、靠坐与阅读低头移动，保留拖动环顾；第三人称仍控制同一个人物。
- 室内书籍接入双手拿取和放回。按钮、B 键、点击桌面书本均可拿书；“拿书阅读”按钮实际拿起模型。书本托举点移到自然臂展内；阅读时 MiniMax 声源随手中的书移动，放回后回到对应桌面。眼镜留在桌边，书签不再悬在空中。
- 室内臀部、后靠、手肘、腿部与脚凳重新适配，修正腿部伸直穿入坐垫及脚部落在脚凳下方的问题。以实际蒙皮鞋底核对脚凳顶面约 `0.544 m`。
- 户外臀部前移并调整脊柱后靠。用现成摇椅的实际网格与人物蒙皮检查背部：中部五个高度带的背部与木椅前缘间隙约 `2.2—6.4 cm`，不再让横档穿过上背。仍需结合实际背面、侧面画面观察，采样不证明所有角度、所有服装都无穿插。
