## 原作到底展示什么

[17张截图核对记录](experiments/14-collage-broll/original-media-review.json)包含7张说明图和两段视频各5处。7张静图分别讲封面、新旧流程、四步法、经验消耗隐喻、材质、五色系统及动作时间表，不是7个独立动画样片。

| 原作 | 观察 | 能支持的结论 |
|---|---|---|
| 四格5秒片，2.50秒 | 按钮/多米诺、剪月亮、纸鹤/阶梯、胶带/烟灰缸等 | 同一拼贴材质可以表现不同概念 |
| 四格0秒 | 绿色面板左边缘有小纸边 | “严格空场起始”未通过 |

| 竖版0/1.25秒 | 空蓝底→黄圆进入 | 可见从空场开始的组装 |
| 竖版2.50/3.75秒 | 手和剪刀形成月牙，余料后段更淡 | 有完成态与停留，但未证实像素级锁定 |

## 可复用的方法

1. **一句口播→一个隐喻。** 先写观众应理解的意思，再选3至6组物件与一个动作。隐喻关系正确比“画面好看”更重要。
2. **先审完成图。** 固定对象、构图、字幕留位与纸片材质，再让它动。作者约70%中心区域是构图建议，不是模型硬约束。
3. **写物理动作。** 每组注明从哪来、做什么、停哪、何时走；滑入、落下、卡位、剪切比“活泼有趣”容易核对。镜头固定，限制新物件与镜头运动。
4. **把结束要求写清。** 单向B-roll可以以完成态停留结束；循环版要另留清场时间。完成参考态不一定是字面文件最后一帧。
5. **审全程。** 检查首帧边缘、组装途中形变/增物、完成构图与停留时间、末态及循环接缝；不能只看漂亮尾图。
6. **分开登记格式。** 生成帧数、GIF每帧延迟、MP4编码fps与真实时长各自记录。改编码fps不能自动产生正确新动作，也不会恢复可编辑图层。

作者反复使用纯色纸底、黑白网点照片、彩纸强调、米白描边、清晰切边和轻纸影。五种颜色的语义是其创作系统，小柚可选少量系列色沿用，不应把它描述成普适心理学结论。

仓库脚本将图像按通用image输入提交，由提示词说明Image 1/2为首尾参考；本轮没有验证端点将其作为强制首尾帧约束。不要把文档中的“exact”措辞当作已测出的精确锁定效果。

## 对小柚的价值与一个具体方案

价值在于把抽象经验、技术解释和观点讲得更直观：保留小柚原口播，在需要解释的3至5秒插入短配画。它增加解释层，不解决写实脸、嘴型和身体动作一致性。

候选句：**“把经验留成方法，下一次就不用从头来过。”**
候选隐喻：**散页被装订成一本可复用的手册。**

| 内容 | 方案 |
|---|---|
| 观众应理解 | 将零散经验保存成可复用方法 |
| 物件 | 散页、手/装订器、完成手册三组 |
| 完成态 | 中央一册手册，边缘不拥挤；中文内容由后期字幕承担 |
| 单向版 | 空场→散页进入→装订→手册停留结束 |
| 循环版 | 压缩组装与停留，另留退场→空场 |
| 风格 | 纯色纸底、黑白网点与米白描边，少量系列强调色 |
| 先检查 | 比喻是否讲对、物件是否够少、字幕是否有位置 |
| 再检查 | 边缘、形变、完成态漂移、停留、结束要求与口播衔接 |

具体[隐喻卡](experiments/14-collage-broll/metaphor-card.example.json)、[动作计划](experiments/14-collage-broll/motion-plan.example.json)和[验收表](experiments/14-collage-broll/qa.template.csv)均已准备，仍是未执行方案。

若需要逐物件精准卡点、改色或单独换纸片，先做分层资产，再接第13条的代码编排思路；生成GIF不会自动提供PSD/透明分层。代码和生成纹理可以配合，不应把它们写成非此即彼。

## 成本、许可与未决项

文章“0成本”指作者使用已经付费的订阅额度，不再逐条支付视频API费。订阅、配额、失败重试、人工修正与导出时间都应记录。仓库旧报价不作为当前价格；代码MIT也不自动覆盖参考图、字体、人物或模型服务的使用权。
