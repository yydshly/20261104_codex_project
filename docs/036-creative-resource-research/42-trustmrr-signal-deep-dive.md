## 具体分析

### 验证收入和推算利润是两步

TrustMRR 可从多个支付平台读取收入。API 将最近 30 天收入、月度经常性收入和总收入分列，还有可空的利润率字段。

依据为 TrustMRR FAQ 和 API 字典。

### 访客分母需要同源比对

公开访客数据可能来自多个分析来源，字段可为空或取搜索点击。收入还可能来自续费、邀约、集成和线下渠道。小粉丝数无法判断客户从哪来。

依据为 TrustMRR API / 对帖子数字的证据审阅。

### 原帖的个案未能配对

帖子没有可打开的企业主页、逐日流水或对应会话数据。将其作为选题渠道线索，核实收入窗口再判断。

依据为 原帖。

### 小柚应试交付任务

查是否有人为一条可用口播、可迭代场景模板、表情包代制付款。把输出、价格、服务范围和返工成本同时记入。

依据为 与第28条数字资产交付相接。

### 评估付费路径能否迁移

同类榜单找 3 项产品，比较价格与渠道，补自己的算力、人工、授权、支付成本。项目利润和支付意愿要靠自己的记录。

依据为 小柚试填方法。
