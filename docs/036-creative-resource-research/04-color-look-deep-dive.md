# 04 用参考色调建立小柚的后期风格

研究日期：2026-11-21。已核对原片4处画面及官网内置示例，导出两份LUT并检查结构。未用小柚素材测试，未验证目标剪辑器往返。

## 本条带来的价值

01至03处理动作、身份与参考资产，04补上成片的颜色观感。可执行成果是“目标色调参考＋LUT＋导出参数＋逐镜头检查”，让小柚同类镜头从同一风格起步。是否减少返工和省时，仍需小柚素材验证。

## 用于小柚的流程

1. 保留原底片和03的中性角色母版，另外输出调色副本。
2. 记录输入色彩条件，按镜头处理曝光和白平衡差异，再试参考风格。
3. 参考图用于确定肤色、白衣和暗部观感；保存.cube、参考来源和全部参数。
4. 同一小柚的室内、室外、暗光各做未调色、半量、全量对照，逐镜头检查，最后回看短片和真实导出。

LUT按RGB值映射颜色，不能修复脸型、身体动作或口型。[Blackmagic官方手册](https://documents.blackmagicdesign.com/UserManuals/DaVinciResolveReferenceManual.pdf)

输入LUT需要与其设计的色彩条件对应；不能把本轮未验证的浏览器示例直接当成任意Log或HDR转换。[Adobe官方色彩管理文档](https://helpx.adobe.com/premiere/desktop/correct-color/set-up-color-management/color-management-using-clip-modify.html)

本地处理是官网及[隐私政策](https://blitzluts.com/privacy/)的说明，本轮未做独立隐私审计；页面访问、统计和媒体内容上传不能混为一谈。
