## 实际检查：引用PNG包含什么

用本项目[只读解析脚本](experiments/12-hdr-avatar/inspect_public_png.py)读取这张公开CDN响应的46815字节，仅保存结构JSON和哈希，不另存或改写原图。[完整结果](experiments/12-hdr-avatar/png-structure-review.json)。

| 检查项 | 实际结果 | 证据含义 |
|---|---|---|
| 尺寸/编码 | 400×400，8位索引色，256色调色板 | 与引用配方的交付形态相近 |
| 块顺序 | IHDR → iCCP → PLTE → tRNS → IDAT → IEND | 此响应含透明度表，PNG层未见cICP |
| CRC | 全部通过，无尾随字节 | 块传输/结构校验，不是画质或亮度验收 |
| ICC名/描述 | Rec.2100 PQ / Rec. ITU-R BT.2100 PQ | 存在PQ色彩声明 |
| ICC内部cicp | 9 / 16 / 0 / 1 | 内部ICC标签与PNG层cICP是不同结构 |
| 未做 | 完整ICC变换审计、像素亮度、显示尼特、平台前后对照 | 不宣称10倍、普遍兼容或平台固定保留规则 |

文件SHA-256：
`01a9dc86de9e302949829f5bf3a24de0ee99598793f1778bcf9cd15f3cddebbc`

W3C PNG第三版支持用色彩信息解释像素，并规定可理解的cICP优先级。实际颜色还依赖解码与显示。这张图有PQ声明，不能仅凭配置名称判断像素映射正确；也不能把“8位”单独当作不是HDR的判据。

原帖“X删cICP留iCCP”在本次结果中有相符现象，但我们没有上传前文件。没有前后链路与重复样本，就不能把单个响应变成平台永久规则。

## 作者配方：可借思路与待验证参数

Eian方案包含分区亮度、发丝遮罩、缩小、线性光转换、调色板与色彩块等步骤。最值得借的是：**背景与脸分开处理，并检查小头像里的异常亮点和边缘。**

203尼特是作者使用的参考设定，不是所有手机界面白的固定值。背景10倍、脸部较低等数值是目标，不能承诺设备实到相同峰值。小柚先按脸部与品牌色建立基准，再试有限的高光范围；不为了亮度自动更换品牌颜色。

只给普通像素加PQ/ICC标签不算完成转换。SDR转制是在现有内容上安排亮度，也无法补回已经剪掉的纹理。我们没有执行引用配方，也没有验证其具体缩小、量化或遮罩参数优劣。

## 两个工具的当前差异

界面核对记录见[tool-interface-review.json](experiments/12-hdr-avatar/tool-interface-review.json)。以下均为站点说明，未复测导出或平台表现：

| 项目 | xhdr.app | xhdr.org |
|---|---|---|
| 头像/图片 | 图片入口；文案称X-ready 400×400、256色PQ PNG | 头像页标400×400、16位HDR PNG |
| 视频 | 页面称8位H.264 HLG、BT.2020，指向X | 页面标HEVC MP4、PQ/BT.2020，指向Instagram/Facebook |
| X视频说法 | 称逐步开放，账号可能不同 | 建议跳过X，并称X视频为标准范围 |
| 头像上传建议 | 桌面网页、不裁切；提到iPhone App处理问题 | 头像页提示手机X App |
| 执行条件 | 自述免费、浏览器本地处理 | 自述免费、本地处理；视频需能用WebCodecs编码HEVC |

这些说明不能拼成一条保证成功的步骤。它们可能针对不同格式、时间、客户端或账号。我们未得到可覆盖这些情况的平台HDR保留承诺；应记录实际工具和入口，再检查平台返回文件与播放端。

“文件不离开设备”是网站自述，本轮没有以用户素材测试或做网络审计。没有关注解锁、登录、上传或编码操作。

## 对小柚的具体价值

1. **增加可比较的展示版本。** 头像背景或视频灯光可以试局部高光，脸、发型、服装与品牌色仍按原母版验收。
2. **建立头像与成片交付规范。** 文件结构、平台变体、HDR屏与普通屏分别记录，避免“本地能开”就当整条链路成功。
3. **用最小对照判断投入是否值得。** 同一母版只改亮度映射，先验可读性与辨识度，再考虑主页访问或关注转化。

HDR不自动修复变脸、嘴部偏糊、动作或口型问题。原帖没有可比较的点击/关注数据，所以“更醒目带来增长”保持假设。

## 两条小样路线

**头像/图片：** 保留SDR母版与哈希，只另做一个局部HDR候选。查脸、发际、圆裁、48/64像素、色阶与亮点；在HDR环境和普通屏分别看。X官方当前建议400×400，文件最大2MB、可用PNG等格式，这不是HDR保留保证。

**视频：** 选约5秒自有片，包含脸、亮物、暗部和字幕；保存同片SDR/HDR输出。查高光闪变、肤色、字幕、原有音画质量与平台回退。不要把某站面向其他平台的格式直接当作X必过规格。

实际变更头像会涉及账号状态：X官方说明更换头像可能触发蓝标复核。本轮仅研究，没有改账号或发布。相关操作不能充当研究完成的必备步骤。
