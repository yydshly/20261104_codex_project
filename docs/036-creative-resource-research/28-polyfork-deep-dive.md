# 第28条 · Polyfork 参数化模型站

## 结论

Polyfork 把三维模型做成带参数的商品，先免费让人试用与导入低模，再卖高清质量、生产效率、分发权和定制服务。小柚可以先试一套原创场景。免费预览回答能否改成想要的效果，付费文件包回答能否拿走并持续制作。

## 怎么把程序做成商品

1. **按用途找。** 原片从单个 GLB 走到目录，再用场景套件把同风格的建筑、人物和道具放在一起。最后用 truck 搜索演示交叉找车。
2. **在付款前看变化。** 原片用吊臂、车身高度、车斗与配色讲明可改范围。实测中，Fox 的 Body length 默认 1.00，范围 0.85–1.15，改到 1.15 后外形随之变化。HD 链接还可预览毛皮与更平滑的材质呈现。
3. **给两类交付。** three.js 的 .mjs 保留运行时参数。GLB 把本次选择保存在网格与材质里供其他工具导入。作者的按需烘焙服务可生成并缓存某个参数组合的 GLB。菜单和文件权益以对应页面为准。
4. **按场景补供给。** 作者介绍，先由规划器拆套件、Gemini 画参照，再由编码代理写模型程序。渲染对比后由人做最终审核。小柚可借同套件验收和留参数的方式。
