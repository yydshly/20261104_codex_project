# 04 调色核对与小柚试验模板

本目录包含官网内置示例导出的两份LUT；它们不是已经为小柚选定的正式风格。

- case04-demo-intensity-0.cube：匹配强度0%，五项微调为0。
- case04-demo-intensity-80.cube：匹配强度80%，五项微调为0。
- export-check.json：两份文件的参数、网格、数值与哈希检查记录。

本轮验证了界面操作和导出结构，没有小柚素材、剪辑器往返或HDR测试结果。

## 小柚的下一轮

1. 取同一已确认角色的室内、室外、暗光各一张图及对应短片；固定一种已确认的SDR色彩流程。
2. 原件保持独立；按镜头处理明显曝光与白平衡差异。
3. 选一张目标色调参考，在代表镜头上调整并保存LUT；记录导出时的强度及所有微调。
4. 在目标剪辑器以未调色、半量、全量对照。编辑器强度与导出强度分别记录。
5. 检查可辨肤色、白衣、高光、头发暗部和渐变；短片检查开头、中段、结尾及真实导出回放。

## 每次需记录

源素材及色彩标签、参考来源、LUT版本与哈希、导出参数、编辑器混合强度、显示/输出设置、异常画面或时点，以及通过/待修/不可评。未知项留空，不根据.cube扩展名猜测输入色彩空间。

当前没有小柚评分、耗时、费用或效果排名。
