# 05 小柚口播清晰感：A/B/C试验模板

状态：仅有研究与试验设计，未处理小柚口播。原帖子是地图视觉原理提问，没有可直接复现的锐化教程。

## 先排查再比较

保存同一素材的原底片、生成区域、合成中间结果和最终编码文件，以同一时点、相同显示尺寸比较。先区分源图模糊、结构缺失、融合边界、重采样/编码与嘴形或同步问题。

## 三个方案

| 方案 | 唯一主动变化 | 固定条件 |
| --- | --- | --- |
| A | 原片，不加增强 | 同一音轨、时间轴、画幅和编码 |
| B | 轻度局部对比 | 与C相同作用范围；记录软件和参数 |
| C | 轻度锐化 | 与B相同作用范围；记录强度、半径和阈值 |

B/C属于方案比较，不把它们当成互不重叠的视觉机制。若使用跟踪与羽化掩模，先核对其在开合口和转头时的位置。

## 验收记录

按实际发布尺寸连续播放，再以100%显示检查嘴部，记录唇缘白边/黑边、牙齿颗粒、皮肤噪点、重影、掩模漂移和锐度波动。只有观感有益且无明显新增问题才保留候选；否则回退并检查上游。清晰感不替代音画与口型正确。

当前没有试验素材、处理输出或评分，不填写最佳参数、成功率、耗时和成本。
