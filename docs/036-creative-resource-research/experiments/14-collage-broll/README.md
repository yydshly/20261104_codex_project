# 小柚一句口播的纸片配画试验

当前为待执行方案，未生成静帧、GIF或MP4，未运行仓库。

示例句：“把经验留成方法，下一次就不用从头来过。”
隐喻：零散纸页装订成可复用手册。例句为研究方案，并非用户已确认的小柚脚本。

## 使用顺序

1. 用真实口播替换metaphor-card.example.json中的候选句，明确观众应理解的意思。
2. 先审完成静帧；让人复述图意，不清楚就改隐喻。
3. 在motion-plan.example.json里选单向停留或循环清场。不能同时要求完成图是文件末帧和末尾空场。
4. 确认实际生成入口、参数和额度，记录到trial-record.template.json；这一步尚未执行。
5. 按qa.template.csv逐阶段核对；通过/失败据实填写，未测保持空值。
6. 保存原始GIF/视频和转码件，分别登记帧数、延迟、fps、尺寸、时长和音轨。
7. 同一口播比较静态图与动画配画，记录理解反馈、尝试数与工时，决定是否建立系列库。

## 最低通过标准

- 隐喻准确说明原句，不用额外长文才能解释。
- 静帧物件少且可读，字幕另加，不生成小柚身份。
- 首帧边缘、途中形变、完成态停留和结束方式均核对；循环另验接缝。
- 导出可播放，时长和画幅符合剪辑需要；字幕与口播同步另验。
- 没有测量就不填省时、省钱或观众理解改善。
