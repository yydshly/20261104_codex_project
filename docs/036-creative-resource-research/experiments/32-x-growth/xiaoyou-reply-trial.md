## 一条候选需要什么

| 字段 | 说明 |
| --- | --- |
| 原帖及作者 | 去重依据，必要时加父帖或具体评论链接 |
| 真实问题与时间 | 正文在问什么，记录发表及最近实质对话的时间 |
| 别人已经回答了什么 | 标明可读范围，标记是否还有空白 |
| 小柚能补什么 | 一条可验证的新信息、自己的实例或能推进讨论的具体问题 |
| 证据和状态 | 对照图、公开资料、版本和时间码，区分亲测、资料核对和待测 |
| 结论 | 入围、待确认、留选题池。人可决定保留或删除 |

**主题相关** 0 无关，1 间接相关，2 正是小柚的制作或内容主题。**证据增量** 0 只有泛评，1 有明确问题或一项旁证，2 能附可回查依据并直接推进。**对话空间** 0 问题已有答案或关闭，1 仍未完全解决，2 新近且有明确交流需求。未检查填“待核”，上线候选先核完三项。如果原帖打不开、已有人给了同等答复或拿不出具体增量，就不进待回区。

## 用近期帖做一轮

1. 取 10 条同主题的公开帖，保留采集时间。人工和辅助组都用这份清单。有人手时分人盲评，只有一人时轮换两轮顺序，并记录记忆可能影响结果。
2. 各轮先核内容和对话，再打分。人工保留 0–3 条，每项都写明增量。分别记录审完一轮所用分钟数、助手推荐总数、人工保留数、错链和重复，分母为零记无建议。
