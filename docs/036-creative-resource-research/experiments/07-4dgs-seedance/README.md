# 07 小柚离线表演参考试验

**尚未执行。** 当前只有原片研究、交接清单和记录模板，没有采集、重建或小柚生成结果。

目标：先判断小柚短片的表演约束是否有价值，再判断多机位的额外投入是否必要；本轮未执行任何采集或生成。

## 材料

- 一段5至8秒已授权表演：包含一次露齿笑或挤眼、一次手势与一次有限转头，保持动作顺序可辨。
- 小柚已确认的身份参考与镜头要求；不拿原帖人物冒充小柚。
- 实际可用的视频参考入口及其输入条件，记录模型、版本与模式；不预设能导入4DGS。
- 后续如有多机位方案，需取得同拍次原片、同步/标定资料、重建渲染及生成输入记录；当前没有这些资产。

## 步骤

1. 写明3至4个表演事件及其时间窗，区分必须保持的表情/动作和允许改变的服装/场景。
2. 先保留单机位原片，按实际可用入口做小柚小样；记录全部候选、失败点与操作成本，不能把设想写成已跑通。
3. 对照表情幅度与出现顺序、动作接触、视角和身份。若失败先定位是参考被遮挡、输入条件不合适还是生成没有跟随。
4. 只有存在具体视角需求时才进入多机位阶段；先验同步、标定和重建，不先假定增加相机即可解决。
5. 若能取得同拍次数据，选一条原相机视角与4D渲染相机尽量对齐，保持小柚参考、模型版本、输出长度及提示词接近，记录不可控差异；需要多次输出才谈稳定性。
6. 逐层保存原表演、重建参考和最终结果，记录人工、处理与重试成本，再决定是否适合离线宣传片；不外推到实时互动。

## 验收

- 露齿笑、挤眼、鼓腮或其他指定表情的顺序与时点可比；保留率未实测时不填写百分比。
- 手势、遮挡和接触无明显新增畸变；腿部或背面如果不在采集范围内，单独标明生成补足区域与未知来源。
- 小柚身份、发型、服装关键特征在转头与表情变化中保持可接受；与表演跟随分开评分。
- 原片→重建→生成均有对应文件及失败时点，未取得的阶段保持缺失，不伪造中间结果。
- 记录所有候选与实际费用/耗时；单机位与多机位素材或条件不同须注明，不声称严格因果提升。
- 本轮reproduced和个人digested保持不变；没有小柚样片、实测保真率或成本节省结果。

## 记录

- [trial-record.template.json](trial-record.template.json)：未运行指标保持null，不填0或推测百分比。任何身份/表演分数需先写明评分定义与证据，所有候选保留记录。
- [camera-manifest.template.csv](camera-manifest.template.csv)：每路素材一行，按实际相机数量填，模板不要求15台。同步偏移单位写清；有时码仍需核对实际同步与漂移。
- [表演事件模板](performance-events.template.csv)：先定事件与时间窗，允许改变的项目单列；本模板不把原片取样秒数当演员事件真值。
- [原片检查记录](original-video-review.json)：属于研究证据，不是复现通过记录。

可用片段的总成本需包含采集/整理/同步标定/重建/渲染/生成/人工审查和重试；资产可复用部分与每次生成分开。不同时段重拍、不同演员或不同镜头不构成严格的单机位/多机位因果对照。只有拿到相应原始数据才进入后续阶段。
