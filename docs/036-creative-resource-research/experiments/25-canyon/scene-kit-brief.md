# 小柚原创雨窗工作室 · 场景包候选规格

目标买家为需要可改背景的数字人口播创作者和制作小型网页作品的开发者。先用同一时段、天气和镜头可控的房间做自己的两条片，记录修改耗时，再看外部买家能否独立操作。

## 包内文件

|文件或目录|用途|
|---|---|
|preview/|两个灯光方案的图与 10–15 秒视频、静态海报|
|dist/|可直接通过支持的 HTTP 方式运行的构建|
|src/ 与锁文件|可重建的场景与依赖版本|
|assets/|自制或许可可分发的模型、纹理、音效与来源表|
|presets/|日间、夜雨两套灯光和固定、缓推两套镜头配置|
|README、LICENSE、THIRD-PARTY|启动、改稿、环境、文件大小、授权、更新与支持范围|

## 从试用到付费

1. 同一布景做两条自己的预览，记下每次改灯、改镜头和导出的用时。
2. 让 3–5 位有实际需求的试用者按文档启动、换一套光线和机位并生成可用预览，记录设备、阻塞和支持时间。
3. 用试用者的用途和交付成本做上架判断。把通知意向、试用通过、成交、退款和支持分别记录。
4. 定价需覆盖平台费用和交付支持。计算每单实际到账减该单的支持、交付及退款成本，再比较累计可回收的制作工时。

状态为研究候选。原创场景、试用和价格均待验证。
