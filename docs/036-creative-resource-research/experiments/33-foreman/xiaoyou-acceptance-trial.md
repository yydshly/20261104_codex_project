制作完成时记录候选版本、路径、文件大小及内容哈希、生成时间，附原音与参考。文件内容更新时用新候选身份。复核者先确认打开的是记录里的版本，报告绑定规格版本和候选文件。

## 每条检查怎么留证据

| 验收项 | 复核方法 | 典型证据 |
| --- | --- | --- |
| 文件可播放 | 打开同一候选，正常速度播完 | 文件名、内容哈希、播放结论 |
| 时长、画幅、音轨 | 核导出属性，确认原音可听 | 文件属性、实际时长与尺寸 |
| 身份一致与动态细节 | 用身份参考对照起、中、尾和疑点 | 参考版本、时间码、截图 |
| 唇音同步 | 有原音时正常速度听看，再复查明显闭唇和重音 | 对应字词、时间码和观感，必要时分辨是否字幕偏移 |
| 字幕与出片退化 | 校对文字和遮挡，完整播放看返工后的接缝 | 时间码、文字、画面异常 |
| 复核结论 | 任一必要项明确不满足记退修。无已知阻挡但必要证据缺失记待核。全通过可提交负责人签收 | 版本、检查者、证据状态、下一位处理人 |

## 桌面推演记录

| 假设输入 | 独立复核结论 | 后续动作 |
| --- | --- | --- |
| v01 播放、规格与视听均过 | 通过 v01 | 负责人按 v01 的报告、文件和规格签收 |
| v02 画面可播，00:02.40 某个闭唇与原音有可重现错拍 | 退修 v02 | 制作人局部修正并提交新导出，在 00:02.40 复核，完整播放确认接缝 |
| v02 原音不可取得，其他项暂未见明确缺陷 | 待核 v02 | 素材负责人补约定音频，复核者核版本后补验同步 |
| v03 更换片尾字幕，提交时沿用 v01 已通过记录 | v03 待核，等待独立复核 | 保留 v01 报告，按 v03 重新核片，签收时引用 v03 |
