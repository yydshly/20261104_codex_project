# 09 小柚轻动角色首轮试验

**未执行。** 当前只有原作与资料研究，没有制作、导入、导出或发布小柚资产。

目标：用一张已授权小柚插画只验收眨眼与轻微转头，确认分层/绑定质量及一种真实交付；本轮未执行。

## 材料

- 一张身份与构图已确认的小柚插画及授权依据，保留静态母版。
- 适用所选工具的分层PSD与遮挡补画；没有就先完成资产准备，不能用平面图假装已绑定。
- 明确交付是轻动视频/录屏，还是.doll与对应播放器；Cubism需求另记录。
- 记录实际工具版本、资产、参数范围、设备和输出文件；不预设原作参数可照搬。

## 执行顺序

1. 确定需要保留的脸、发型、服装、饰品和留白，写明首轮仅两项动作。
2. 拆层并单独检查隐藏区域与透明边缘；保留工作稿和导入稿，区分底图与补画内容。
3. 在后续试验中检查自动识别，校正头颈点、眼睑线和错层，不断扩大动作前先修静态外观。
4. 分别检查眨眼全过程和有限转头，再回看两者同时发生的边缘与身份变化。
5. 按真实需要导出：模型路线回读.doll并另验HTML；内容路线检查视频连续播放和首末衔接，不假定有内置录制。
6. 记录失败时点、人工修图/绑定时间和回读证据，再决定是否扩展口型/面捕或做传播对照。

## 验收

- 原图、分层PSD、模型与输出之间能追溯；不将四张引用图当作已知输入输出真值。
- 小幅动作无明显脸型漂移、眼睛错层、发际露洞、饰品断开或颈部切口。
- 眨眼形状与眼白裁切自然；转头幅度按素材能力决定，不保证任意角度。
- 模型能在对应播放器重开，HTML或视频在目标环境实际可用；格式兼容不靠后缀猜测。
- 若做循环，记录首末姿态和速度的衔接；仅首末截图相似不能代替连续回放。
- 传播收益、耗时和成本未测保持空；reproduced和个人digested分别记录。
