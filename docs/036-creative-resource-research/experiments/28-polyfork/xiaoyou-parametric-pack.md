# 小柚雨窗工作室 · 可编辑场景包试卖记录

试做目标是让创作者自己改出能用的背景，并判断是否愿意买走可编辑文件。样品和报价尚待验证。记录来自本轮实测后填写。

| 参数 | 免费样品试什么 | 正式包检查 |
| --- | --- | --- |
| 灯光色温 | 在冷雨、暖窗中切换 | 人脸区域或人物占位处的颜色与背景分离 |
| 窗外雨量 | 无雨、小雨、大雨或有边界滑杆 | 字幕可读、窗口边界与粒子性能 |
| 桌面配色 | 三套色板 | 同机位回读材质，无异常闪烁 |

固定人物位置、房间尺寸、同一机位与字幕安全区。每项保存默认值、上下界和复位。第一轮用同机位对照图和一段预览验证需求。

## 交付规格

- 可离线运行的可编辑工程、所有纳入交付的自有资产、三套预设和一个目标格式。
- 参数表、使用说明、版本、兼容工具与许可范围。纳入第三方资产时附可分发依据。
- 导出格式与动态效果分别验收。例如选 GLB 时检查模型、材质和比例。雨粒与动态光效如果依赖页面代码，在交付说明中明确标注。
- 一次性文件包定价与专属工作量分别记录。定制只在确认机位、道具、品牌色、交付形式与验收条件后报价。

## 三位创作者的试用
