# 小柚15秒中文代码配画试验（待执行）

本轮仅完成原作/文档/接口研究，没有安装cinecode、运行其源码、生成静帧/声音/MP4或发起素材上传。

候选主题：为什么只换参考图，画面还是不稳定？
解释方式：人物参考、动作、后期三层卡片，再提出“一次只改一项，再对照结果”。
这是本项目拟稿，不是用户已确认的小柚台词，不代表已经测出这三项的具体效果。

## 使用顺序

1. 换入真实可使用的中文口播，以实际音频长度修正beat-sheet.example.json。
2. 先审问题、三层卡片与结论的静帧；没有真实A/B素材时使用中性占位，不虚构结果。
3. 记录当前工具、浏览器/GPU、字体和实际路径，核对中文版断句与词时。
4. 用帧号/稳定输入控制图形，拟定15秒、24fps；这是方案参数，不是原片参数。
5. 做草稿，再按9:16与16:9分别构图，不能只裁切。
6. 用qa.template.csv检查中文字形/句读、手机阅读、帧边界、声音/字幕和导出元数据。
7. 把尝试数、agent/TTS/素材成本、人工/渲染分钟记入trial-record.template.json。没有基准不报告节省。
