制作过程中遇到过什么，后来怎样处理
  • 整机背景不足。 车床片从局部加工扩展到整机导览，让观众先建立空间位置。
  • 镜头和标注读不清。 多轮静帧检查后修正裁切、进排气箭头、偏心销引线和成品直径对齐。
  • 导出资源与环境问题。 3D 渲染改为串行执行，路径追踪成为可用路线，最终交付采用实际核验过的分辨率和帧率。
  • 音轨时间映射出错。 曾出现视频完整而后半段旁白无声。修正工程分段音轨的输入时间范围，重新导出混音，再逐段对照七段原始旁白的时间位置。
  • 会动还需要讲明白。 在发动机网页补上活塞销动作、气门开闭读数与飞轮标记，让结构、动作和讲解相互对应。

这些修正说明，分镜预览、完整音轨检查和具体教学问题都要进入制作流程。静帧评审只能检查它看得到的部分，连贯运动与音画同步还需要单独验证。

04 / 工具与原理 每一步由谁承担

一部片怎样被做出来

Tesseract 是代理可操作的视觉制作与渲染运行时，以工程组织剪辑、二维动画、三维场景和音轨。本轮把这些环节接成了一条可交付的工作流。

  1. 01

    描述与分镜

    用户提出教学问题，Codex 拆解章节、讲稿、零件动作和机位。

  2. 02

    模型与旁白

    编写几何和关键帧，MiniMax 生成七段中文语音素材。

  3. 03

    可编辑工程

    Tesseract 保存 3D 场景、二维标注、镜头与分段音轨。

  4. 04

    预览与渲染

    看代表帧、校验动作和音轨，再用本地 Runtime 逐帧渲染。

  5. 05

    交付与继续改

    FFmpeg 封装校准后的声音、字幕与章节，保留 MP4 和 .tsrct。

Tesseract 工程里存了什么

它记录素材引用、图层顺序、片段在时间线的位置，以及关键帧、文字、相机、灯光和材料等数据。原素材的取段范围和成片上的播放位置分别记录。

某一时刻需要出画面时，Runtime 按时间计算属性，在关键帧间插值，把场景和图层合成出来。修改一处镜头或文字后，可以继续保存同一份工程并重新导出所需时间范围。

官方 Runtime 说明 ↗

网页发动机为什么可以拖动

网页里的发动机由 Three.js 实时绘制。曲轴角度驱动连杆和活塞的位置，网页读取旁白播放时间来选择章节和动作。用户可以自由旋转机位或手动暂停。

Tesseract 的成片使用编排好的机位和时间线，交付通用 MP4。两种表现共享教学主题，网页源码与 .tsrct 分别保存和维护。本轮没有验证两者之间自动同步修改。

Skills 的作用，以及“用自然语言制作”怎样发生

Tesseract 官方技能包把 Runtime 的命令、工程 schema、例子和制作指导交给代理。Codex 结合这些规则与实际工具输出，编写并执行具体的工程操作。

本轮网页使用 Vite 与 Three.js，视频制作脚本则创建 Tesseract 几何、动画和音轨。MiniMax 调用单独读取本机配置，网页提供的是生成后的音频文件，页面源码包含演示素材和交互逻辑。

技能负责帮助代理正确调用，模型和动作仍需设计，预览后还要根据画面修改。复杂软件行为以运行时的实际版本接口为准。

明确分工 音频来自哪里

MiniMax 生成旁白

“音频是不是 Tesseract 自带的”是讨论中的一个重点。本例所有发动机讲解来自 MiniMax 语音合成，生成后再作为文件导入。Tesseract 负责音轨的时序与混音，最终 MP4 的声音和字幕由 FFmpeg 封装。

使用边界 针对具体任务判断

按需求确认编辑能力

我们使用了剪辑、二维图层、三维场景与音轨中的一部分。多机位自动同步、自动字幕转录、特定编解码格式等需求，需要分别确认实现路径和外部工具。

扩展接口、工程转换与许可
  • 自己的控制界面。 应用可以通过对应版本的 Runtime 接口修改工程属性、保存并请求预览。我们当前网页直接控制 Three.js 模型，Tesseract 工程编辑界面属于扩展方向。
  • 模板与批量生成。 可以围绕共同的项目结构，把型号、标题、尺寸、语言或镜头作为参数。跨型号批量制作的维护成本与稳定性还需试验。
  • 与其他代理或服务连接。 能执行工具的代理可按文档接口工作。队列、资产管理、版本管理和权限需要由集成应用负责。
  • Adobe 项目转换。 官方说明为部分兼容，After Effects 导出仍属实验性，需检查字体、图层、效果与媒体路径。
  • 引擎获取与许可。 官方提供有文档接口的免费本地二进制，部署、分发和商业嵌入按对应发行许可核对。引擎源码未公开。

先做一个手摇单缸模型

我们讨论过从纸板活塞、连杆和带偏心销的飞轮理解运动关系。这个实体制作方案尚未制作或试运行。

  1. 固定飞轮中心轴，用两条平行导轨限制活塞的运动方向。
  2. 在离飞轮中心 10 mm 的位置放一枚销，用连杆连接偏心销与活塞。
  3. 手摇飞轮，观察偏心距与行程的关系，示例行程约 20 mm。
