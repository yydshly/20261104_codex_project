# 头像、壁纸与漫画成品验收

日期：2026-11-12。范围：独立创作、实际导出文件、网页用途对比和下载。

## 实际交付

| 类别 | 下载文件 | 具体用途 |
| --- | --- | --- |
| 头像 | 1024×1024、512×512 方形 PNG | 账号头像，网页提供 32/64/96px 圆形显示检查 |
| 手机壁纸 | 1080×2400 JPG | 窗台睡猫，上方为时钟与通知留白 |
| 桌面壁纸 | 1920×1080 JPG | 窗边伸展猫，左侧为桌面图标留白 |
| 漫画整页 | 1200×1560 PNG | 四格完整阅读与分享 |
| 漫画长条 | 800×3510 PNG | 手机按顺序滚动阅读 |
| 独立分镜 | 4 张 550×550 PNG | 保存、分格分享或继续编辑 |

三类分别提供 ZIP 包，总包包含 10 个图像文件与使用说明，共 11 项。两个 WebP 为网页轻量预览，原图下载保持 PNG/JPG。

## 创作与边界

- 使用内置 `image_gen.imagegen`，按同一白猫参考分别生成头像、手机壁纸、桌面壁纸、四格故事图，共四次调用，未使用 CLI/API 回退。
- 四格图包含等饭、推碗、按住打字的手、放下满碗并一起休息四个新场景与动作；不是重复原表情排版。
- 本地处理仅做尺寸适配、分镜提取、中文文案排版和文件打包。完整提示词、输入、原始输出路径：`assets/carrier-sources/generation-record.json`。
- 源图尺寸：头像 1254×1254、手机壁纸 941×1672、桌面壁纸 1672×941、漫画图 1254×1254。壁纸和漫画长条经过缩放；文件标注的是导出尺寸，不宣称原生 4K。
- 所有角色与故事均为虚构样品，设计取舍为当前示例方案，真实偏好需使用者确认。未制作动态屏保、虚拟出镜模型或印刷绘本。
- 原有表情套装、参考照片和前后对照文件保留。

## 检查结果

- `npm run check` 通过；新增产品脚本、构建脚本与原有脚本语法正常。
- `npm run build:carriers` 成功，输出尺寸、字节数与 SHA-256 记录在 `assets/carrier-products/manifest.json`。
- 三个分包和总包由 .NET ZIP 读取，每项都能完整解压到内存，长度与条目记录一致。
- 本地页面 HTTP 200，WebP MIME 为 `image/webp`。浏览器中成品预览全部载入，未记录 JavaScript 错误，无重复 ID。
- 三类卡片并排展示实际作品、下载入口和用途；下方表格比较设计判断及价值检验。
- 头像详情展示新画面与三个显示尺寸，下载的是独立新头像。
- 壁纸可切换手机/桌面，分别引用不同的独立插画文件；界面参照可开关，不进入下载文件。
- 漫画可展开手机长条原图阅读，关闭后返回；详情另有可展开的剧情文字。
- 浏览器实际下载总包、1024px 头像、手机壁纸、漫画长条；四个下载文件的 SHA-256 均与网页原件一致。
- 390×844 窄屏检查：文档可用宽度 375px，无横向溢出；三张卡片各 339px，垂直排列；漫画原图对话框 341px，可内部滚动阅读与关闭。
- 桌面检查为 1280px 视口，图像与下载入口正常；结束时调用临时视口 reset，关闭本轮临时预览服务。
