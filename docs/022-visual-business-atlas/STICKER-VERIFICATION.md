# 表情成品与效果库验收

日期：2026-11-12。当前验收范围为真实素材文件与网页效果展示，未包含客户成交或平台投稿。

## 产物

- 内置 `image_gen.imagegen` 生成三套原创透明动作图集，保留原始副本和完整提示词。
- 完成 12 张 GIF、12 张透明 PNG、48 张独立关键帧和三份 ZIP 下载包。
- 每张 GIF 解码为 240×240、四帧、1.36 秒循环；四幅源帧的哈希各不相同。
- GIF 文件约 54–63 KB，包含透明索引，帧角落透明。PNG 为 480×480。
- 逐项视觉检查总览：中文无乱码，角色完整，文字能在小尺寸下阅读。动画属于四帧关键动作样品。
- 三份 ZIP 均能由 Windows 的 ZIP 读取库打开；每份包含四个 GIF、四个 PNG、使用说明及文件信息，共十个条目。
- 文件尺寸、源图与 GIF 哈希、帧数见 `assets/stickers/manifest.json`。

## 桌面网页

- 首页与 GIF 响应均为 HTTP 200，动图 MIME 为 `image/gif`。
- 宠物、情侣、小店三套切换成功；每套四张表情和对应对话更新。
- 选择“贴贴”后，对话显示安慰语境，下载链接指向 `pet/hug.gif`。
- 选择“到家啦”后，对话显示报平安语境。
- 选择“正在打包”后，对话显示小店取货语境；“再发一次”增加演示回复。
- “暂停动图”将实际 GIF 源切换为静态 PNG；切换套装后仍保持暂停状态。详情中的缩略图同样遵守播放状态。
- 深色底检查可切换，便于查看透明边缘与文字白描边。
- 实际下载小店“正在打包”GIF 与小店整套 ZIP，下载文件 SHA-256 均与项目源文件一致。
- 从客服方向详情可回到小店对应作品。
- 默认显示四个已有对应样品的方向；关闭“只看有成品”后可探索全部 18 个方向。
- 未制作独立作品的方向在卡片与详情中明确标注；未把情侣图套作社群案例、或把客服动图当作整套月度运营案例。
- 浏览器重新加载后无 JavaScript 错误，样品图像均加载成功。

## 手机布局

- 测试 390×844 视口设定，实际文档可用宽度 375px；文档宽度同为 375px，无横向溢出。
- 样品面板宽 339px，四张表情分两列展示，对话与下载区域位于下方。
- 手机端选择“开饭啦”后，当前表情与对话语境正确更新。
- 临时视口覆盖在验收结束时移除。

## 明确边界

角色为原创虚构样品，不是客户照片还原、真人肖像定制或已成交案例。表情可下载试用；客户愿意付费、照片还原效果、商业许可与平台投稿需分别核对。浏览器对话仅为本页效果演示，不连接微信、不发外部消息。

只读取页面不需要安装图像制作依赖。`npm run build:stickers` 是使用本地图集重新组装的开发命令，不会调用生成模型。
