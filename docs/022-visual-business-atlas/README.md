# 造物生意图谱

从“具体载体 → 使用场景 → 承载价值”组织理解：新增九类常见载体地图，并用同一只傲娇白猫演示聊天表情、桌面互动、四格分镜和立牌陈列的不同用法。各项分别标注已有成品、网页可试或概念示意，避免把载体演示当作全部完成的商品。

头像、壁纸和漫画已升级为独立创作的可下载成品：1024/512px 头像、1080×2400 手机壁纸、1920×1080 桌面壁纸、《休息一下，也算正事》四格整页、手机长条与四张独立分镜。网页并排比较用途、设计取舍和价值验证，并支持放大、壁纸界面参照切换与单文件/整包下载。

先查看成品，再理解价值。网页内已制作三套原创表情包：宠物“橘猫奶盖”、情侣“两个人的日常”、小店“吐司店长”，共 12 张真实 GIF、12 张透明 PNG 和三份下载包。相应作品连接到宠物定制、情侣定制、小店吉祥物、客服回复四个方向；其余方向明确标注对应作品待制作。

查看网页不需要构建工具、外部字体、图片服务或网络 API。动图是生成的动作帧组装成的实际 GIF 文件。

## 打开

直接用浏览器打开本目录的 `index.html`，或在本目录执行：

```powershell
npm start
```

默认访问 <http://127.0.0.1:5208/>。可以用 `VISUAL_ATLAS_PORT` 环境变量更改端口。`Ctrl+C` 关闭预览服务器。所有功能均在浏览器本地运行。

```powershell
npm run check
```

## 内容

- 载体地图：表情包、头像与虚拟形象、桌面宠物、壁纸与屏保、漫画与绘本、知识卡与手册、互动小游戏与实验台、计算器与功能网页、实体文创，共九类。
- 每类说明具体形态、使用时机、承载价值、实际交付件、验证问题及当前状态。表情、头像、两张静态壁纸、四格漫画和成本计算器可用；桌面互动、检查卡和尺寸实验可在本页试用；立牌为概念示意。动态屏保、虚拟出镜模型和印刷绘本未制作。
- 18 个方向的卡片、详情与对比表补入“具体载体”；设计前后案例也标明本例使用的载体，可返回地图。
- 人的价值设计对照：三组模拟需求与参考照片，现有通用样品与本轮参考约束下新生成的静态成品并排展示；逐项解释“发现的细节 → 设计判断 → 成品核对”。
- 案例支持放大图片、隐藏判断先看图、逐案自检、下载定向 PNG 与设计简报，并可跳到相应原套装。
- 18 个方向，分为情感定制、商家经营、内容传播、场景活动、数字资产、制作工具六类。
- 每个方向含客户、付费价值、最小交付包、验收、首位客户、扩展路线、验证实验、继续与调整信号、交付边界和相关资料。
- 成品效果库：三套切换、四张动图选择、具体对话语境、追加演示回复、暂停播放、深色底透明检查、单张 GIF/PNG 与整套 ZIP 下载。
- 默认只看四个已有成品的方向。取消“只看有成品”可查看全部 18 个方向；搜索、场景/客户筛选及排序仍可使用。
- 最多三个方向并排对比；四条逐步扩展路径。
- 根据目标、能力与客户接触面生成三条起步建议。排序基于明示的启发式规则，不是收入概率。
- 按方向生成五项七天实验清单，浏览器本地保存勾选，可下载 Markdown 清单和当前成本输入。
- 单笔交付计算器：实付金额、现金成本、费率、目标劳动报酬、制作/修改/获客时间。
- 资料分级：创作者案例、已读取的官方资料、待复核官方入口。

## 判断与证据

这是产品机会图谱，不是已完成的市场调研。方向、优先级、难度与复购潜力均为编辑分析假设。官方资料仅用于支持交付形式、产品结构与平台要求，不用于推断销量。未复制原帖收益数字为收入证据，也未将微信旧教程规格当作最新规范。

资料核对日期：2026-11-12。主要资料为 LINE Custom Stickers、Etsy 数字商品帮助与 Creativity Standards、Canva Brand Kit、Printful 按需印刷说明、itch.io 创作者质量指引。页面内提供精确原始链接。微信表情官网本次无法直接读取，标注待复核。

每小时现金结余 = (实付金额 × (1 − 费率) − 现金成本) ÷ 总工作小时。

达到目标的参考实付价 = (现金成本 + 目标时薪 × 总工作小时) ÷ (1 − 费率)。

结余不是净利润；税费、设备折旧、固定开支未计算。默认数字仅为演示。

## 人的价值：前后设计对照

新增的三例使用内置 `image_gen.imagegen` 先生成明确标注的模拟参考照片，再把参考照片与原套装的风格样品作为两张输入，按具体需求生成定向静态成品。原通用样品未降质、未覆盖。

- 宠物：从通用橘猫“开饭啦”，到保留白猫黑耳、鼻边斑与项圈的“碗空了”，表现克制的催饭。
- 情侣：从通用拥抱，到保留圆眼镜、短卷发与服装配色的“我陪着你”，表达安静陪伴。
- 小店：从“收到，安排”，到借用商品和包装视觉、正在核实状态的“我确认一下”，区分看到消息与确认有货。

这是需求贴合度的设计演示，不是单变量模型评测或真实客户案例。照片、需求与设计判断均为示例，仍需真人确认偏好与使用效果。自检勾选只表示当前页面使用者核对过某问题，不是满意度或客观评分。

`assets/case-sources/generation-record.json` 保存参考与定向生成的完整提示词、输入文件及状态；原始生成副本也在该目录。`assets/case-studies/` 保存网页用参考图、新成品、对照总览与源文件哈希。可运行 `npm run build:cases` 用已有本地原图重新排版导出，不调用生成模型。

后续可扩展为真实实验台账：在方向下记录样品、访谈、实际订单、总工时与复购，再以自己的证据调整推荐顺序。添加外部平台发布、收款或客户资料收集需单独设计与授权。

比较选择和清单状态写入当前浏览器的 `visual-business-atlas:v1`。没有账号、外部追踪、照片上传、生成任务或自动发布。读取 `file://` 时个别浏览器可能限制本地保存，可使用本地服务器和清单下载。
