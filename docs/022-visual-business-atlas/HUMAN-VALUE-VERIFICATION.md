# 人的价值与前后设计对照验收

日期：2026-11-12。范围：模拟素材下可追溯的设计过程、实际新生成文件与网页交互；真实客户确认仍待进行。

## 内容与素材

- 三组案例：宠物的辨识与傲娇催饭、情侣的安静陪伴、小店的待确认回复。
- 先用内置 image_gen 生成三张明确标注的模拟参考照片，再分别将参考照片和原通用样品作为两张输入，生成三张定向静态图。
- 三张定向图实际使用本轮参考生成，保留原始输出副本；导出为 480×480 透明 PNG，并独立排版中文文案。
- 前版是原有通用 PNG，保留原文件与品质；本轮没有改写原套装。
- 参考、完整提示词、输入文件与状态：`assets/case-sources/generation-record.json`。
- 新图片和参考哈希、原样品哈希：`assets/case-studies/manifest.json`。
- 对照总览：`assets/case-studies/design-comparisons.png`。
- 参考与需求均为模拟，设计判断为示例方案，没有真实客户满意度、成交或审批记录。提示词中的角色措辞不作为客户确认的证据。

## 实际浏览器交互

- 页面 HTTP 200、JPEG 参考图 HTTP 200 且 MIME 为 image/jpeg；浏览器无 JavaScript 错误。
- 三例均能显示参考、现有通用 PNG 和本轮定向 PNG。
- 宠物版显示黑耳白猫、空碗、“碗空了”；情侣版显示圆眼镜、姜黄开衫、深蓝外套与“我陪着你”；小店版显示查看记录姿态与“我确认一下”。
- 每例展示模拟需求、发送时刻、三项设计判断、成品核对问题及人的贡献。
- 判断区域可隐藏并重新展开；案例图片可打开原生 dialog 放大，再用按钮关闭。
- 键盘 Home 切回首个案例，tab 与 panel 的关联正确。
- 宠物勾选一项后，情侣初始仍为零；情侣的独立勾选可在返回后保留。测试结束后已还原勾选。
- 定向 PNG 下载和设计简报下载已通过浏览器实际触发。
- “查看原套装与动图”进入相应原套装，原套装“看这个方向的设计对照”能返回同类案例。

## 解释边界

这组比较展示“参考依据 + 情绪意图 + 使用语境 → 设计取舍 → 成品对照 → 本人确认”的方法。它不构成真实照片定制精度、市场需求或付费结果的证明。自检只表示页面使用者核对了某个问题，不是客户评分。
