第一轮演示提案：一个“梦境入口”

目前官方文档中，Midjourney 的 Style Reference 用于参考色彩、光线和材质等整体风格；Image Prompts 可影响内容、构图与颜色。它们提供控制方向，具体画面仍需制作、筛选与修改。Style Reference 文档 ↗ · Image Prompts 文档 ↗

MiniMax 当前视频文档支持首帧／尾帧图生视频与多种参考输入，可作为“先定关键帧，再设计运动”的候选路线。文档所列能力不等于已经达到我们的镜头目标，也不能据此复原作者当时的工作流。MiniMax 视频文档 ↗

DaVinci 的 Color 页面可处理亮暗、色彩平衡、风格及 HDR。本轮制作建议先保证 SDR 版本稳定，再按实际显示目标决定 HDR 交付；HDR 的具体参数不能从参考 JPEG 反推。DaVinci Color 官方说明 ↗
