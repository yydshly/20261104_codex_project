# 从说明页面到图像展览 · 本轮审视与修改

用户目标：网页本身呈现带艺术氛围的情绪图像，让人有空间停留、观看，再决定是否深入研究。

## 修改前：本轮现场截图

1. **首页 — 偏离观看目标。** `01-before-home.jpg`。图像位于右栏，左侧大标题、两种行动入口、底部能力说明与顶部功能导航同时进入第一眼。优点是研究主题清楚；问题是观看者会先理解任务，再看图像。较小的导航和辅助说明也存在阅读尺寸风险。
2. **实验区 — 工具清楚，观看被打断。** `02-before-workbench.jpg`。编号直接覆盖图像，右栏是参数、解释与感受选择。适合分析已经看过的作品，缺少不被提示干预的初次观看空间。截图可以证明视觉层级，不能证明用户情绪或停留时间。

## 已实施的取舍

- 首页成为完整图像视野，移除首屏的研究任务、能力条与导出入口。画面主体是雾湖、柳枝、天鹅和远处的灯光。
- 增加本项目新生成的《雾湖与垂柳》《午后与亚麻帘》。采用低微对比、柔和高光、微细颗粒与有空间关系的构图，保留作品原件。
- 湖边、窗边、午后三种片刻由用户手动切换，不自动轮播打断观看。短句和细小的场景导航保持从属。
- 提供“只看画面”，隐藏画面文字和多余导航；可用同一按钮或 Escape 返回。隐藏的交互入口同时设为 inert，避免键盘停留在不可见控件上。
- 向下滚动是带间隔的图像与少量文字。原有分析、收藏与创作工具移入默认收起的“作品背后”，在用户明确打开后呈现。
- 新增艺术意图说明：湖边以围合的观看位置、微小生命和远处人迹建立情绪；午后以空椅、透光帘与旧木材表现时间与人的痕迹。
- 手机湖边使用独立取景锚点，避免天鹅被右侧裁掉；文字下移，让天鹅与标题各有空间。
- 声音默认关闭，只在用户点击后播放合成环境声；图像轻微移视是浏览器动画。减少动态效果的系统设置下停用动画。

## 已核对的使用路径

1. **进入观看 — 可用。** 默认展示完整艺术图像，研究折叠区为关闭状态，辅助功能不会出现在首屏的无障碍阅读树里。
2. **选择片刻 — 可用。** 湖边、午后、窗边切换时，主图、可见替代文本、标题、选中状态与下载文件一同更新。聚焦图像容器后 ArrowRight 切到窗边。
3. **只看画面 — 可用。** 已实际查看纯图像画面，Escape 恢复文字。
4. **按需声音 — 控件可用。** 点击后 aria-pressed 为 true，再次点击为 false。没有在本次审视中对听觉效果作主观质量判断。
5. **带走图像 — 可用。** 用网页下载了 `quiet-place-lake.png`，与项目湖边原件作 SHA-256 比对。
6. **展开作品背后 — 可用。** 展开后仍能访问账号分析、案例、参数实验和产出区域。原有选中的童趣题材、自定义文案与收藏计数沿用原数据，未重新初始化。
7. **手机取景 — 已修正。** 390 × 844 下页面宽度 375，无横向溢出；天鹅完整入画，字与主体错开。结束后恢复原视口。
8. **研究区导航与下载 — 已修正并复核。** 快速跳到创作区时曾出现重复滚动：原生锚点与脚本同时要求滚动。改为只有折叠状态下的深链接才由脚本补充定位。之后创作段顶部位于视口内 147px，导出按钮可见；通过按钮实际下载了 `cozy-delight-brief.md`。

最终默认桌面视口宽度为 978px，页面宽度 963px，无横向溢出；研究区域关闭、声音关闭，前台图像缺失数为 0。最终 warning/error 日志为空。`npm run check` 包含新展览脚本。

## 资料与限制

这是视觉与交互修订的审视，没有测量观看者情绪、平均停留时长或商业转化。两张新作品的实际生成指令保存在 `../atmosphere-generation-prompts.json`。不能从我们对画面的解读，推出所有观众都产生相同感受。

旧版三个源码文件留在本目录供对照；日记库、应用缓存和其他子项目均不在修改范围内。
